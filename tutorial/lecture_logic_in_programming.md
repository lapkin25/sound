## 2. Вступление (10 мин)

**Тезис-рамка курса:** модели вычислений отвечают на вопрос «как машина вычисляет», логика — «что гарантированно верно о вычислении». Мост между ними — неподвижная точка.

Повторить одну строку по каждой модели (по одной карточке):

- МТ: вычисление = перезапись ленты, конфигурация = снимок.

**Ключевое различение для всей лекции:**

- λ-исчисление — синтаксис вычисления (как вычислять);

## 3. Постановка задачи: gcd (15 мин)

Программа:

```
вход: a, b              // оба ≥ 1
L0: if (b == 0) return a;
L1: t = a % b;
L2: a = b;
L3: b = t;
    goto L0;
```

**Вопрос к аудитории:** безопасен ли этот код для всех входов? Перебор невозможен — входов бесконечно много.

**Две формулы:**

1. Безопасность: ∀ пути π: старт → L1 ⟹ σ_π(b) ≥ 1.
2. Завершаемость: вариант V = b, убывание: b_new = a % b < b при b ≥ 1.

Обе — утверждения обо всех исполнениях: квантор ∀ по путям.

**Вердикты анализатора:**

| Вердикт | Смысл |
|---|---|
| SAFE | формула истинна на всех исполнениях (инвариант найден) |
| UNSAFE | контрпример: конкретный путь, где всё ломается |
| MAYBE | аппроксимации не хватило — не разобрался (не «ошибка») |

## 4. Конкретная семантика (20 мин)

### 4.1 Состояния и реляции

σ ∈ Σ, σ : Var → Z. Семантика команды — бинарное отношение [[c]] ⊆ Σ × Σ.

Развилка — одно тождественное отображение с двумя метками-предусловиями:

- ребро «да» помечено p(σ) ≡ σ(b) = 0;
- ребро «нет» — ¬p(σ).

### 4.2 Сборка семантики

X : L → P(Σ) — отображение узлов графа в множества состояний. Система уравнений:

X(L) = ⋃ по всем входящим рёбрам (L', c, L): [[c]](X(L')).

Узел L0 в цикле ссылается сам на себя через X(L3): **цикл = рекурсивное уравнение**. Это первый щелчок лекции.

### 4.3 Прогон руками (перед переходом к коробкам)

Запуск a=4, b=6: (4,6) → (6,4) → (4,2) → (2,0) → ответ 2. Один конкретный мир.

## 5. Решётки, фильтры, развилка (15 мин)

### 5.1 Коробки как домен

D = I × I, [l,u] ∈ I; порядок — покоординатное включение; γ(I) — конкретизация (какому множеству состояний соответствует коробка); пара Галуа (α, γ), свойство γ ∘ α ⊇ id.

### 5.2 Фильтр

F_p(I) = I ⊓ α({σ ∈ γ(I) : p(σ)}).

Пример b = [0,3]: в «да» остаётся [0,0], в «нет» — [1,3]. Ничего не потеряно — пучок рассортирован.

Пример b = [1,10]: γ(I) ∩ {p} = ∅, значит F_p(I) = ⊥; пустая ветка отсекается автоматически — эвристика стала частным случаем формулы.

### 5.3 Мост в логику (одним слайдом)

Правило Хоара для ветвления:

```
{P ∧ p} E1 {Q}    {P ∧ ¬p} E2 {Q}
────────────────────────────────────
   {P} if p goto E1 else E2 {Q}
```

Метки рёбер = конъюнкции посылок. wp(if p then E1 else E2, Q) = (p ⇒ wp(E1,Q)) ∧ (¬p ⇒ wp(E2,Q)) — та же структура, что у целей в GKC-лабе.

## 6. Неподвижная точка (12 мин)

### 6.1 Сборка оператора

F : D^|L| → D^|L|; монотонность из монотонности компонент и операции соединения.

X* = F(X*).

### 6.2 Прогон числами (главная таблица лекции)

Раунд 1:

| Узел | Формула | Результат |
|---|---|---|
| L0 | σ0 ⊔ T(⊥) | [1,10]×[1,10] |
| L1 | F_{≠0}(X(L0)) | [1,10]×[1,10] |
| L2 | t = a % b | t ∈ [0,9] |
| L3 | a := b; b := t | a∈[1,10], b∈[0,9] |

Раунд 2: X(L0) = [1,10]×[1,10] ⊔ [1,10]×[0,9] = [1,10]×[0,10]; фильтр восстанавливает X(L1) = [1,10]×[1,10] — без изменений. X* = F(X*). Вердикт SAFE.

**Фраза для запоминания:** соединение расширило, фильтр сузил — сеть уравнений выжала инвариант сама.

### 6.3 Теоремы

- Кнастерм–Тарски: в полной решётке μF = объединение цепочки X^k существует.
- Клини: при конечной высоте h цепочка стабилизируется не более чем за h шагов.
- Расхождение: μF не достигается ни при каком конечном k, если высота бесконечна — существование есть, вычислимости нет.

### 6.4 Связь с λ

Разворачивание Y F = итерация Клини; нормальная форма = стабилизация; Y работает только в нормальном порядке редукции.

## 7. Widening и narrowing (10 мин)

Пример ломки: L0: x = x + 1; goto L0 даёт цепочку [0,0], [0,1], [0,2], … — бесконечную.

Определение ∇: (W1) x ⊑ x∇y и y ⊑ x∇y; (W2) любая итерация y_{k+1} = y_k ∇ x_{k+1} стационарна.

Правило интервалов: граница сохраняется, если не выросла; выросла — уходит в ±∞.

Доказательство остановки потенциалом: Φ(X) = число конечных границ ≤ 2n; каждое строгое применение уменьшает Φ минимум на 1; не более 2n строгих шагов.

Цена: пост-неподвижная точка F(y*) ⊑ y*, μF ⊑ X*_∇; полнота потеряна, корректность — нет.

Narrowing △: зеркальный оператор, заполняет бесконечности; мера — «сколько бесконечных границ осталось»; итог: μF ⊑ z* ⊑ X*_∇.

**Главный тезис раздела:** идеальный ∇ (звуковой + останавливающийся + точный) решал бы проблему остановки, значит, не существует. Widening — инженерный ответ на неразрешимость Гёделя–Чёрча.

## 8. Логический слой и финал (8 мин)

- Sound-анализ = автоматизированная аппроксимация логики Хоара снизу.
- MM (метод максимального контрпримера): обратный вывод от цели; когда интервалы деградировали до MAYBE, логика добирает то, что потеряли интервалы: находит инвариант b ≥ 1 и сертификат варианта V = b.
- Контрпример = тропа фреймов ⟨старт, a=1, b=0⟩ → ⟨L0⟩ → ⟨L1, a%0⟩ — пройти руками.

**Финальный тезис лекции (дословно на слайд):**

> Модели вычислений различаются синтаксисом, но упираются в один и тот же предел — неразрешимость, — и все преодолевают его одним и тем же ходом: аппроксимацией с гарантированной остановкой.

## 9. Тезисы для экзамена

1. λ — синтаксис вычисления; sound и Хоар — семантика; мост — неподвижная точка.
2. Цикл в программе = рекурсивное уравнение в системе сборки семантики.
3. Фильтр на развилке = встреча I ⊓ α({p}); пустая ветка = ⊥.
4. Join расширяет, фильтр сужает; их согласованность — commuting square Кузо.
5. Кнастерм–Тарски даёт существование, Клини — вычислимость при конечной высоте.
6. Widening: звуковой + останавливающийся, но не монотонный и не точный.
7. Двойной soundness: корректность анализа + корректность системы вывода.
