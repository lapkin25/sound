# SCore — реферат слоёв 2 и 4 (граф, формат, валидация)

Версия спецификации: **sound-0.5.1** (правки закона нумерации по итогам прогона)

## 1. Словарь core/2 (заморожен)

Операции: `const`, `ref`, `set`, `plus`, `mul`, `sub`, `quotient`, `mod`, `pow`,
`eq`, `lt`, `and2`, `or2`, `not2`, `part`, `snoc`, `foldlist`, `fold2`, `if2`,
и словарные ошибки (`err:bounds`, `err:lenmismatch`, `err:div0` и др.).
Арифметика Int64 — по модулю 2^64, канонические политики для каждого знака
фиксированы словарём; Float64 — по IEEE-754 с зафиксированными правилами
округления и punning'ом на границе платформ.

**core/3-d1** (черновик-1, не заморожен): core/2 + `tail` + `len`. Появились из
языка мер Аккорда (счётчики и ленты без операций над списками не выражаемы).
Трейсы объявляют `dict: core/3-d1`; реплей старой версии их не принимает.
Кандидаты следующего шага: `closure`, `extcall`.

## 2. Канон TRIOMAT/2 (вариант A)

Самозакрывающаяся запись значения. Скалярный элемент — префикс `16:` + hex-строка
(то же, что самозакрывающаяся запись), длина списков — `19:` + число:

```
A = 3|19:16:0000000000000002,19:16:0000000000000003,19:16:0000000000000004
```

Правило уточнено (в раннем наброске была лишняя внутренняя обёртка элемента).
Точный разбор литералов — через рационалы `m/10^e` на стороне транскриптора;
`strtod` хоста запрещён; зеркальный тест hex <-> decimal обязателен.

## 3. Формат ANF/1

```
# sound-anf/1
spec: <имя>
sound: sound-0.5.1
dict: core/2 | core/3-d1
canon: triomat/2
handles: <перечень хэндлов>          ; обязательное поле (см. §5)
seed: none

--- environment ---
<param> = <канон TRIOMAT>

--- funcs ---
<тела правил: узлы u0..uK>

--- graph ---
t0 const ...
tK-1 set ...

--- journal ---
t0 ... -> <значение>
...

fingerprint: <64 hex>
```

Снапшот самодостаточен: валидируется и реплеится без Piano-исходника.
Платформенно-слепой: ни дат, ни рантайма, ни обстоятельств запуска.

## 4. Закон нумерации (sound-0.5.1)

- Нумерация `t0..tK-1` — детерминированная функция исходника: сортировка по
  канонической строке узла `(op, args)` с фиксированными тай-брейками.
- **Дедупликация**: узлы с одинаковой канонической строкой сливаются (гарантия
  тождества — одна строка = одно значение). **Исключение: чтения хэндлов никогда
  не сливаются** — повторный `ref h` всегда отдельный узел (статический граф не
  знает, встретится ли `set` между чтениями в конкретном исполнении; правка по
  дефекту AddLong2, см. run_report.md).
- Тай-брейк для повторов — по первым употреблениям имени в Piano-исходнике.
- Чтения немутабельных ячеек (факты, параметры) сливаются: значение фиксировано.
- Значения в журнал не влияют на нумерацию (вход как снапшот: `param` снижается
  в `environment`, узел `const` его не содержит — инвариант графа к входу).

## 5. Валидатор: девять критериев

| № | Критерий |
|---|---|
| 1 | шапка полна, версии согласованы |
| 2 | все ссылки на узлы определены и предшествуют |
| 3 | граф — DAG (по хэндлам: от записи к чтению) |
| 4 | журнал — подпоследовательность графа |
| 5 | цель `set` значится в `handles:` (поле введено в 0.5.1) |
| 6 | нет дубликатов канонических строк (кроме чтений хэндлов) |
| 7а | повтор — ошибка, если не слился и не является `ref h` |
| 7б | самопоследовательность журнала: значение каждого `ref h` равно последнему предшествующему `set h` (переформулирован в 0.5.1; старая формулировка снята как опиравшаяся на недопустимое слияние) |
| 8 | канонические строки значений корректны по TRIOMAT/2 |
| 9 | отпечаток воспроизводится по рецепту §6 |

Валидатор работает без Piano-исходника.

## 6. Отпечаток (fingerprint)

Рецепт: канонические строки журнала последовательно -> SHA-256. Конечен по
построению (тотальность Piano). Совпадение отпечатков двух исполнений на
независимых платформах — вердикт реплея, байт-в-байт.

## 7. Транскриптор: пять стадий

1. разбор в дерево выражений;
2. типизация и разрешимость имён;
3. канонизация (точный разбор литералов, стирание сахара, порядок правил);
4. спуск в ANF с назначением канонической нумерации и дедупликацией;
5. эмиссия снапшота ANF/1.

Ключевое обязательство: транскриптор **не вычисляет арифметику** (кроме точного
разбора литералов) — раскладывает, а не исполняет.
