# Trio — реферат слоя 3 (рантайм-дублёры и реплей)

Версия спецификации: **sound-0.5.1**

## 1. Что такое реплей

Реплей — повторное исполнение вычисления рантаймом-дублёром по одному лишь
снапшоту ANF/1: без Piano-исходника, без компилятора, без доступа к автору.
Алгоритм протокола:

1. вычеркнуть из графа неисполненные узлы;
2. вычислить каждый узел журнала **собственной** арифметикой дублёра;
3. вывести результат через ворота платформы в канон TRIOMAT;
4. сверить hex-строками с записанным (поузлово), пересчитать отпечаток.

Реплей — не доверие платформе, а воспроизведение: расхождение на строке `t5`
— конкретная строка, а не «особенность платформы». Реплей не интерпретирует
язык: сжат до арифметики словаря; ни разбора, ни типизации, ни выбора порядка —
всё уже решено транскриптором.

## 2. Ворота платформ

| Платформа | Гейт | Замечания |
|---|---|---|
| Octave | `num2hex` | целые и вещественные — через hex-представление IEEE-754 |
| C | `punning` + бинарный экспорт | union int64/double, вывод в hex |
| WL | Export с точной записью | рационалы/гекс |

Назначение ворот: **ни одна операция словаря не совершается «руками платформы»** —
платформа поставляет только арифметику по модулю 2^64 и IEEE-754, всё остальное
(порядок, списки, складывания) уже зашито в граф.

## 3. Что дублёр не делает

- не читает Piano-исходник (его у него нет);
- не выполняет дедупликацию и нумерацию — граф уже готов;
- не проверяет типы и меры (Аккорд) — это компиляция;
- не принимает решений о порядке исполнения — он записан в графе и журнале;
- не решает, что случится, а что нет — неисполненное вычёркивается по журналу.

## 4. Роль в схеме «вход как снапшот»

Дублёру не важны даты, среда и обстоятельства запуска: вход уже зашит в
`environment` снапшота. Цепочка снапшотов (эволюция состояния) реплеится
по звеньям: выход звена k сверяется отпечатком, затем подаётся фактом в звено k+1.
Каждое звено — отдельный проверяемый шаг истории системы.

## 5. Сверка и вердикт

Совпадение поузловых hex-строк журнала => совпадение отпечатков => вычисление
воспроизведено байт-в-байт на независимой платформе. Расхождение — конкретная
строка журнала: разбор не «в среднем», а по шагам. Дефект транскриптора (AddLong2)
и дефект закона (sound-0.5 -> 0.5.1) пойманы именно этой схемой; см. run_report.md.
