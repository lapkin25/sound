# Piano — спецификация языка
## версия спецификации: 0.5.1 (грамматика заморожена, см. grammar_freeze_v1)
## статус: frozen v0.5.1; резервы перечислены в §8, обещаний по ним нет

---

## 1. Место в стеке

Piano — уровень 0 стека Sound: язык программ. Программа — декларативный
исходник, тотальный по построению. Единственный носитель исполнения —
журнал sound-0.5.1: транскриптор развёртывает программу в линейный журнал,
реплейеры-дублёры исполняют журнал. Piano никогда не исполняется
напрямую; «запустить программу» значит «прогнать её журнал».

## 2. Программа

Программа — один снапшот. Снапшот состоит из секций:

    snapshot <имя>
      fact <имя> = <выражение>          -- факты; замораживаются правилами П1–П6
      rule <имя> <арг> ... = <выражение> -- правила; чистые функции
      foldlist <акк> <фн> <список>       -- единственная итерация
      target <выражение>                 -- целевое выражение (точка входа ENTR-V)

Ограничения снапшота:
- факты заморожены до первого использования; правило П6 запрещает
  факту зависеть от факта, объявленного позже (см. accord.md, секции 1–8);
- правила — чистые функции: никаких побочных эффектов, никаких чтений
  вне аргументов и фактов;
- целевое выражение одно. Оно задаёт точку входа транскрипции (ENTR-V):
  развёртка журнала начинается с него. Точка входа реплея — всегда
  шаг 1 журнала; эти два входа не смешиваются.

## 3. Значения

- Целые числа (арифметика — словарь core/2: plus, sub, mul; переполнение
  не определено на уровне языка и является пунктом сверки платформ).
- Булевы значения: 0 / 1.
- Кортежи: (e1, ..., ek), k >= 2; вложенность разрешена.
- Списки: пустой список nil (d2-2), наращивание snoc, разбор tail/part.
- Хэндлы: ссылки на растущие структуры (ref/set/setv).
- Значения-ошибки помеченного типа (err K) — честные значения, см. §7.

## 4. Выражения

Выражение — литерал, имя, вызов операции словаря, кортежный литерал
или bind-форма. Вызов строго по словарю; расширения словаря — только
через реестр d2 (d2_candidates.md), не через грамматику.

Позиционное чтение кортежа: part E k, k — константа-индекс.
Индексация списков — через pair-подобные конструкции core/2/3-d1;
динамический индекс допустим и попадает под R4 (см. accord.md).

If — строгий в значениях: обе ветви вычисляются всегда, If выбирает
одно из двух уже вычисленных значений. Управления потоком нет; мёртвых
ветвей в строгом журнале нет (исключение — кандидат d2-3, ограничен).

## 5. bind

    bind (x1, ..., xk) = E

- Не более одного bind на правило, в начале тела.
- Имена уникальны в пределах правила.
- Правило ленивого раскрытия (grammar_freeze_v1, §3):
  bind-объявление НЕ порождает узлов журнала; part E i материализуется
  в точке первого вхождения имени xi, порядок — по первому вхождению;
  неиспользуемые имена не материализуются вовсе.
- Следствие (приёмочный тест): журнал bind-версии программы обязан
  совпасть байт-в-байт с журналом явной версии. Сахар невидим для
  реплееров, отпечатка и ИНВ-Р.

## 6. foldlist

    foldlist acc f list

Тотальная итерация: f применяется к каждому элементу списка, аккумулятор
передаётся по цепочке. Тотальность — в конструкции; обязательства Аккорда
не нужны (паттерн Маркова). Развёртка — явные проходы: ИНВ-Р.4,
итерация только явная, никакого скрытого цикла в рантайме.

## 7. Ошибки

Различаются две категории — смешение категорий считается дефектом
транскриптора:

- err K — честное значение помеченного типа, порождаемое программой
  (пример: DemoRanges, err 2). Реплеер обязан его исполнять как значение.
- Нарушение контракта журнала (висячая ссылка, выход индекса setv
  за границы, ломка канонической нумерации) — дефект журнала,
  реплеер обязан остановиться с MISMATCH, не «переваривать».

## 8. Границы заморозки (frozen v0.5.1)

Заморожено: синтаксис секций снапшота, форма выражений, кортежные
литералы (построение и позиционное чтение), bind (§5), семантика If,
форма foldlist.

Резервы (не заморожены, без обещаний обратной совместимости):
- равенство кортежей (потенциальный канал зависимости от репрезентации —
  только через отдельную заявку в реестр);
- именованные поля кортежей;
- образцы в заголовках правил;
- расширения словаря — через реестр d2, не сюда.

Изменение замороженного — только новая версия спецификации с миграцией
всего корпуса Piano-исходников и эталонных журналов.

## 9. Контракт транскрипции

Транскриптор обязан:
1. выдавать журнал sound-0.5.1 с канонической нумерацией,
   ссылки строго назад (ИНВ-Р.1);
2. раскрывать bind по правилу §5 (лениво, по первому вхождению);
3. для рекурсивных программ предъявлять линейный журнал ДО проверки
   Аккорда (accord.md, секция 9) — мера не декларируется, а доказывается
   на развёртке;
4. проходить эталонную сверку: выход трейса сверяется с независимым
   расчётом задачи (контур 3) — реплей не ловит самосогласованную
   неверную семантику (находка d2-5, DemoMaze2).
