# Реестр — решения F-3: mul и ступень 1
# 2026-11-23

СЛОВАРЬ v0.6 (надстройка над 0.5.3):
  + mul — атомарная операция фиксированной семантики (целочисленное умножение).
  Принцип минимальности (пересмотрен по решению арбитра):
    словарь содержит атомарные операции фиксированной семантики; требование
    «каждая операция выводима из остальных» снято — при нём словарь пуст
    (plus сам ни из чего не выводим). Выводимость проверяется для конструкций,
    претендующих на производность.
  Фиксация иллюзии: div/mod обладали «широкой» семантикой с первого дня;
    делители-константы во всех кейсах маскировали невыводимость mul —
    маскировка была на глаз, не по существу.

УПРАВЛЕНИЕ, ступень 1:
  foldlist по вычисленному списку легализован (число итераций = len списка).
  Деградация предсказания зафиксирована: «ровно N» -> «формула + граница».
  Терминация: per-case аргумент (для foldlist — убывание длины tail-цепочки).

Карта F-3 (остаток):
  ступень 2 — bounded while (LOOP-уровень, примитивная рекурсия);
  ступень 3 — рекурсия с журнальным инлайнингом (терминация per-case);
  unbounded while — вне карты, отдельный осознанный виток.
  filter — решён отрицательно без введения (вердикт B: guard-конструкция
    справилась; запись окончательная при закрытии F-3).
  версионирование: прежние 10 эталонов остаются валидными для 0.5.3;
    v0.6 — надстройка, обратной ломки нет.
