# DemoReverse — ворота реконструкции исходника

Статус: ЗЕЛЁНЫЙ. Порождено 50/50 строк, байт-в-байт совпадение с эталоном.
Финал: [6,2,9,5,1,4,-1,3]. ИНВ-Р.1: нарушений нет.

## Структура гипотезы
1. Программа — НЕ foldlist. Вложенная цепочка snoc с литеральными убывающими индексами
   (7..0); frozen-грамматика выражает реверс без расширений словаря.
2. Двойной ref (t0018, t0019) объясняется алиасом: fact L = arr8.
   Дeref имени-алиаса даёт ref(ref A) — первый part стоит на t0019,
   последующие итерации deref'ят хендл алиаса напрямую (t0023..).
3. const nil — синглтон эмиттера: один узел кормит и базу сборки arr8 (t0003),
   и базу цепочки реверса (t0022). Объясняет отсутствие второго const nil.
4. Порядок эмиссии: глубина-первым, слева направо; материализация имён ленивая —
   arr8 собирается в момент первого употребления L.

## Проверка потребителей
t0018: 8 потребителей; t0019: 1 потребитель; t0050: 0 (результат программы).
