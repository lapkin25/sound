Дельта ИНВ-Р.1 / канона:
  1. Индекс part — вычисляемый узел: part g s, где s сам вычислен (deref вычисляемых операндов).
  2. Заготовка потребляется по индексу-счётчику (part g s); хвост-цепочка не нужна.
  3. Вложенная свёртка выразима: шаги внутреннего foldlist перемежаются между
     итерациями внешнего; каждый шаг — одна операция канона.
  4. Элемент заготовки всегда потреблён (аргумент if), серой зоны «неиспользуемый
     элемент» нет: term = if flag d e, при flag=0 ноль элемента даёт нулевой вклад.

Ограничение конструкции (в протокол): квадрат корректен для цифр n <= 6 —
длина заготовки статическая. Для n > 6 требуется расширение заготовки
(новый факт), семантика не меняется.
