2. §4 Якорь аккумулятора: шаг на каждый узел AST исходника. `const nil`
   может встречаться в журнале более одного раза (DemoReverse2: два).
   Синглтон-правило отозвано.
3. §4 Порядок эмиссии: сборка списка(ов) -> якорь -> итерации (индекс 0..L-1).
4. §5 cons: prepend, список первым. Маркер формата sound-0.5.2 при cons в журнале.
5. §6 foldlist: порядок аргументов f acc list подтверждён двумя эталонами
   (DemoMax, DemoReverse2). Легаси-порядок DemoSum закрыт.
