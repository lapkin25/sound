# Спецификация foldlist — v0.2

Правка по воротам DemoMax (57 шагов, байт-в-байт, 0 расхождений). v0.1 отменяется; ниже — полный действующий текст с отмеченными изменениями против v0.1.

## 1. Сигнатура и семантика

`foldlist acc f list` — левая свёртка, обход от головы к хвосту.

Порядок аргументов **f acc list** (эталон DemoMax; легаси DemoSum с порядком list f acc — до-канонная эпоха, не норма).

[f (dots f (f (a, x_1), x_2) dots, x_n)]

Для n = 0 результат — a. Пустой список — легальный вход: ноль итераций.

## 2. Требования к операндам (DictErr)

- f — имя существующего правила арности ровно 2.
- list — выражение со статически выводимой списочностью и длиной; скалярный третий операнд — DictErr.
- acc — любое выражение; типизация — забота реплея.

## 3. Канон итерации (замена §3 v0.1)

Итерация — **3 шага скелета + шаги тела**:

```
ref <операнд> -> ?     ; deref операнда, на каждую итерацию
const <i> -> ?         ; бегущий индекс 0..N-1
part ref idx -> ?      ; элемент
<шаги тела>            ; acc <- хендл последнего шага тела
```

- Обход бегущим индексом по фиксированному операнду; tail-цепочки нет.
- ref на каждую итерацию обязателен.
- `part` всегда deref-ит список через шаг `ref`; `len`, `tail`, `snoc` берут хендл напрямую.
- Индекс — собственный шаг `const`; `part` принимает его хендл.
- Подстановка в тело — напрямую (без прокси-ref), тело встраивается с перенумерацией; повторное употребление имени — новые узлы.
- Цепочка аккумулятора: итерация k ссылается на последний шаг тела итерации k-1; финальный хендл foldlist — последний шаг тела последней итерации.

## 4. Порядок эмиссии (замена §4 v0.1)

1. Список-база (разворот выражения/факта; поэлементно: const nil, затем const элемента + snoc на каждый элемент — не «один const [...]», правка против v0.1).
2. `len` корня списка-операнда (если операнд — `tail L`, то по L, до снятия головы). Шаг len может остаться непотреблённым — не вычищается.
3. Якорь аккумулятора (разворот acc-выражения; последняя литеральная ступень — const).
4. Операнд (разворот выражения списка-операнда; для `tail L` — шаг tail по хендлу L).
5. Итерации слева направо.

## 5. If

`if c then else`; c != 0 -> then. Обе ветви разворачиваются, невзятая сохраняется («мёртвые» шаги не вычищаются).

## 6. Данные и заголовок журнала

- Неиспользуемые факты шагов не порождают.
- Скалярные факты — const при каждом употреблении (дедупликация запрещена); списочные — материализация один раз, далее ref при deref-контексте.
- Заголовок журнала — три строки: титул (первая строка-комментарий исходника), каноническая строка формата `# формат sound-0.5.1, грамматика v0.5.1 (frozen)`, elems-строка со статическим значением корневого списка.

## 7. Вложенность

Тело может содержать вложенный foldlist; разворачивается рекурсивно, счётчик сквозной. Все программы frozen тотальны — разворот конечен по построению.

## 8. Инварианты и ошибки

- ИНВ-Р.1: все tid-ссылки строго назад; литеральные аргументы const не считаются ссылками.
- Категории: GrammarErr, DictErr — до эмиссии; TranscrErr — защитный слой; типовые ошибки значений — класс «ошибка реплея».
- Реплей сверяет значение len со статически выведенной длиной.
