# O.2 — протокол отпечатка, черновик v0.1 (к арбитражу)

## Известные факты
- Отпечаток встречен ровно один раз: DemoSum, легаси-эра, формат показа `721b9d5c5972…800d`
  (12 hex в начале, 4 в конце).
- Алгоритм, скоуп байтов и кодировка — неизвестны. До их фиксации любой «совпавший» хеш — случайность.
- Обрезок может быть (а) нашей заметкой о полном значении или (б) собственным форматом показа эталона.
  Это различие решает вопрос о принципиальной верифицируемости О.2 — см. Q4.

## Пространство гипотез (матрица o2_hypothesis_matrix.md, 35 кандидатов)
- Алгоритмы: sha256, sha1, md5, sha512-trunc256, blake2b(32).
- Скоупы: полный файл LF / без финального перевода строки / CRLF; только t-строки; только шапка; канонический (без пробелов вокруг ->).
- Кодировка: UTF-8. Регистр hex: нижний (верхний — тривиальное преобразование, в матрицу не включён).

## Решения арбитра
- Q1: алгоритм по умолчанию (кандидат: SHA-256 — длина 64 hex совпадает с ожидаемой длиной отпечатка).
- Q2: скоуп байтов (кандидат: полный файл с финальным переводом строки, LF, UTF-8 — скоуп S1).
- Q3: обязательность строки отпечатка в журнале (кандидат: обязательна, но только для форматов с отпечатком в спецификации).
- Q4: обрезок — свойство эталона или наших заметок? Если эталон сам показывает 16 hex —
  протокол фиксирует «показ: prefix 12 + suffix 4», и полная верификация принципиально невозможна;
  О.2 закрывается как «протокол определён, реверс недоказуем».

## Процедура верификации (как только поступят байты DemoSum)
1. Взять дословный байтовый образ demo_sum.journal.
2. Прогнать 35 кандидатов; критерий успеха — совпадение prefix 12 + suffix 4 (64 бита доказательной силы).
3. Совпадение → протокол фиксируется, DemoSum становится первым верифицированным отпечатком.
4. Несовпадение → реверс признаётся неуспешным; арбитр назначает протокол волевым решением (Q1/Q2),
   DemoSum помечается «легаси, отпечаток вне протокола», новые эталоны несут отпечатки уже по протоколу.

## Критерий закрытия О.2
Либо (3), либо (4). И то и другое закрывает пункт; (4) дешевле и честнее при отсутствии байтов.
