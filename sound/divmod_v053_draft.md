# Соглашение divmod_v053 (ЧЕРНОВИК — по процедуре cons_v052)
Статус: не подписано. Требуется верdict арбитра по пунктам 2, 4, 5.

## 1. Основание
Пункт F-2 реестра: перевод числа в список десятичных цифр требует деления с
остатком. Процедура — та же, что при вводе cons: соглашение -> запись в реестр ->
версия словаря -> кейс -> ворота.

## 2. Операции (словарь v0.5.3)
- `div a b -> Int` — усечённое целочисленное деление (trunc). b = 0 — ошибка реплея.
- `mod a b -> Int` — остаток по тождеству a = (a div b)·b + (a mod b);
  знак остатка = знак делимого.
Для неотрицательных аргументов совпадают с обычными div/mod; кейс оперирует
только неотрицательными, конвенция для отрицательных зафиксирована на всякий случай.

## 3. Что не трогается
Грамматика v0.5.1 frozen — не расширяется. Маркер формата не меняется.

## 4. Кейс DemoBin2DecDigits — дизайн
Ключевое ограничение: foldlist ограничен фиксированным списком, «пока n > 0»
в frozen-семантике не выразить. Дизайн-решение:
- Число итераций задаётся фактом `width`; старшие позиции, не занятые цифрами,
  дают нули (padded-семантика): n = 45, width = 3 -> [0,4,5].
- Аккумулятор несёт пару [n, цифры...] одним списком: n = part acc 0, цифры — хвост.
- Тело итерации (9 шагов): const 0 -> part acc 0 -> const 10 -> mod n 10 ->
  const 10 -> div n 10 -> tail acc -> cons n' (tail) -> cons d (...) .
  Двойной `const 10` — два узла AST, по правилу «шаг на узел».
- Итог: out digits = tail финального acc — цифры старшими вперёд.
- Убирать нули без filter нельзя; filter — слой F-1, не cons-уровень. Не рекомендую.

Два варианта кейса:
(a) n задан фактом (fact n = 45) — минимальный кейс, ворота бьют только по div/mod;
(b) полный конвейер bits -> Horner -> digits в одной программе — сильнее, но
    поднимает новые грамматические вопросы (вложенный foldlist в выражениях,
    deref вычисляемых операндов в 0.5.2 — открытый пункт).
Рекомендация: первый gate на (a), (b) следом как расширенный кейс.

## 5. mul — вопрос арбитра
Горнеру хватает plus (2 шага на удвоение); mul сократил бы до одного, но раздувает
словарь. Рекомендация: отложить (frozen-минимализм).

## 6. Ворота (после подписи)
Исходник -> эмиттер (без правок) -> реплей -> сверка. Внешний якорь: 45 -> [0,4,5],
проверяемо вручную. Пометка self-referential — как у DemoBin2Dec (О.5-стиль).
