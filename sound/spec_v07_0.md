# spec_while v0.7 draft — неограниченный while с per-case терминацией

## 1. Новый оператор

Программа .while (v0.7 draft) состоит из строк:

- `step f = <схема>` — тело шага цикла;
- `stop p = <схема>` — предикат останова (0 — продолжать, 1 — остановиться);
- `entry f(x)` — вход;
- `until p` — имя предиката останова;
- `cert x0 x1 ... xk` (опционально) — per-case сертификат: полный трейс
  от входа до значения, удовлетворяющего stop.

Схемы — подмножество грамматики .pr: comp, prec, pi(k,i), z, s и атомы словаря.
В draft атом `rev` берётся библиотечным: его схемная развертка верифицирована
в demo_prpalstep.pr, здесь он подключается как готовый узел.

## 2. Классы терминации

- **Class A** (v0.7.1, в draft не входит): мера выражена PR-функцией словаря,
  вербикатор проверяет убывание. Пока не реализовано.
- **Class B** (draft): per-case сертификат. Терминация засчитывается только
  для конкретного входа и только при полном проверенном трейсе.

## 3. Инвариант честности

Машина не содержит собственного цикла. Исполнение while — это ровно
проверенный реплей сертификата: каждый переход перепроверяется шаговой
функцией, предикат останова перепроверяется на каждом элементе трейса.

Программа без сертификата не исполняется ни на одном шаге — выдаётся отказ.
Подделанный сертификат отклоняется с указанием первого сбойного перехода.
Машина не умеет крутиться: единственный источник незавершимости (сырой
цикл) в её коде отсутствует по построению.

Частичная проверка запрещена: частичный трейс не доказывает останов,
поэтому сертификат принимается только целиком.

## 4. Коды отказа

- **R-TERM-NOT-CERTIFIED** — while без сертификата.
- **R-CERT-BROKEN** — сертификат есть, проверка не прошла; отчёт перечисляет
  все несовпадения: сбойные переходы, сбои предиката, сбой финала.
- **R-ENTRY-MISMATCH** — вход не совпадает с началом сертификата.

## 5. Границы draft

- step и stop — только схемы над атомами словаря.
- Сертификат проверяется целиком, без срезов и сокращений.
- Class A, общая мера и вербикатор убывания — предмет v0.7.1, не draft.
