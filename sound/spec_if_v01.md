# Канон вычисления if — v0.1

Статус: принят арбитром 2026-11-23 (пункт О.4).

1. Ветвления if вычисляют ОБЕ ветви (жадно). Обоснование: формат журнала
   требует два handle-аргумента у if; невзятая ветвь обязана иметь хендл.
2. Литералы тела правила дают шаг const на каждый узел AST на каждую
   итерацию (продолжение правила «шаг на узел AST», установленного
   DemoReverse2 двойным nil).
3. Семантика: if c then else = then при c != 0, иначе else.
   Порядок аргументов подтверждён фактурой DemoMax (t0026–t0027).
