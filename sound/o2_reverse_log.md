# О.2 — Журнал реверса отпечатка DemoSum (попытка №1)

Дата: 2026-11-23. Статус: отрицательный результат, протокол не восстановлен.

## Входные данные

- Полный отпечаток (из заголовка файла DemoSum.journal):
  `721b9d5c597249d6aec7866090b10306da9cc9944898aac126b0d1149fbd800d`
- Байтовый образ файла: 948 байт, 35 строк (1 заголовок + 34 шага), концы LF, финальный NL есть, BOM нет.

## Ключевое решение по Q4 (закрыто фактурой)

Полная строка отпечатка СУЩЕСТВУЕТ в эталоне — 64 hex-символа.
Ранее обрезок `721b9d5c5972…800d` был артефактом наших заметок, а не формата показа.
Длина 64 hex = 256 бит совместима с SHA-256/SHA3-256/BLAKE2b-256/BLAKE2s.

## Полосы перебора

### Полоса 1 — базовая матрица (450 кандидатов)
Скоупы: полный файл / только шаги (с NL и без) / только заголовок /
заголовок без значения fingerprint.
Нормализации: как есть, без финального NL, CRLF, канон без пробелов вокруг `->`,
сжатые списки (без пробела после запятой), комбинации.
Алгоритмы: md5, sha1, sha224, sha256, sha384, sha512, sha3_256, blake2s, blake2b-256.
Результат: 0 совпадений (включая частичные prefix12/suffix4).

### Полоса 2 — канонические сериализации (792 кандидата)
- строки без хендлов (`s1`, `h8` вырезаны), t-нумерация, plain-нумерация;
- только значения (RHS): через NL / запятую / пробел, сжатые и обычные;
- только операции (const/snoc/part/plus);
- строки без номеров; заголовок с пустым и нулевым fingerprint;
- BOM, strip, CRLF-варианты.
Результат: 0 совпадений.

### Полоса 3 — цепочки и экзотика (20 кандидатов)
- UTF-16 (LE/BE, с BOM и без);
- rolling-цепочки: sha256 поверх hex-звеньев и digest-звеньев,
  по строкам-шагам, по значениям, по всем строкам файла;
- двойной sha256; хеш финального значения и счётчика шагов.
Результат: 0 совпадений.

## Итог реверса

~1262 кандидата, ноль совпадений. При 16-битном suffix4+12-битном prefix12
вероятность случайного частичного совпадения на 1262 пробах порядка 10^-12 —
отрицательный результат достоверный: искомой функции среди перебранных нет.

## Рабочие гипотезы на будущее (не проверяемы сейчас)

1. Отпечаток считается над исходником demo_sum.sound, а не над журналом.
   Исходника в легаси-эре у нас нет — гипотеза непроверяема до его появления.
2. Нормализация, не покрытая перебором (например, канонизация значений
   с внутренним представлением, не совпадающим с текстовым показом).
3. Функция не из семейства стандартных криптохешей.

## Рекомендация (на арбитраж Q1–Q3)

Назначить протокол волевым решением: sha256 над полным файлом, LF, UTF-8 (S1).
DemoSum пометить `легаси: отпечаток вне протокола, функция не восстановлена`.
Все новые эталоны несут отпечатки по протоколу; наши эталоны (DemoMax,
DemoReverse, DemoReverse2, DemoBin2Dec, DemoDivMod) — бэкфилл отпечатков.
