15. Макро for (v0.6.2 draft)

  for i := a to b do B end
    ≡  rng := range_build(a, b); acc := foldlist (B с подстановкой e := i) acc0 rng

  range_build(a, b) — библиотечная лемма (эталон demo_forfold, фаза 1):
    while i < b+1 do rng := snoc rng i; i := i + 1 end bound: b + 1
    Дедукция — once-per-library: i возрастает, b+1 не переопределяется
    телом, страж на последнем обновлении. Все последующие for наследуют
    структурную терминацию фазы свёртки бесплатно.

  Свойства:
  - число итераций зафиксировано на входе: len(rng) до фазы свёртки;
  - счётчик — элемент списка, телом не модифицируем (дисциплина Паскаля);
  - порядок сохранён: snoc при счёте вверх — возрастающий диапазон;
    downto — тот же билдер со счётом вниз;
  - пустой диапазон легален: a > b -> [], ноль итераций;
  - break/continue не выражаются (согласовано с §8).

  Протокол: для for-программ предсказание — steps(n) = C + 9n из
  библиотечной леммы; согласие итераций с границей — по фазе билдера,
  фаза свёртки проверяется tail-цепочкой.

  Статус: draft до воспроизведения парсером всех кейсовых эталонов
  из звук-файлов (критерий готовности парсера, пункт 1 плана).
