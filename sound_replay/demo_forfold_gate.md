# Ворота кейса (ж) — demo_forfold: классический for через foldlist
# 2026-11-23, протокол О.2, грамматика v0.6.1 frozen; синтаксис foldlist-формы — v0.6.2 draft

Тезис кейса: for i := a to b do B end  =  rng := range(a,b); acc := foldlist B acc0 rng.
for НЕ добавляет мощности (в отличие от mul): поверхностная форма, выразимая
словарём. Словарь не растёт — растёт грамматика.

Предсказание (до прогона): steps(n) = 9n + 19
  подготовка 5  = const n, const 0, const nil, const 1, plus n1
  фаза 1: 3n+1  = (страж + snoc + инкремент) x n + выходной страж
  фаза 2: 6n+2  = (len + страж + part + mul + plus + tail) x n + len/страж выхода
  фаза 3: 11    = const 2, mul, plus, mul, mul, const 6, div + 4 (eq)
  n = 10 -> 109. Сошлось.

Границы:
  фаза 1: 10 <= 11 — OK, дедуктивная (n+1 — выражение словаря, вариант Б)
  фаза 2: СТРУКТУРНАЯ — len по tail-цепочке, bound не требуется (§4).
  Первый фрагмент стека, останавливающийся без дедуктивной границы.

Стражи-свидетели: 22 (11 в фазе 1, 11 в фазе 2), контракт соблюдён
(значение 1 на каждом шаге, 0 на выходах). len-узлы потребляются стражами —
не свидетели.

Артефакты развёртки: 0 — оба стража висят на переменных, обновляемых телами
последними (i в фазе 1, rest в фазе 2): профилактика §5.7 сработала в обеих
фазах. Первый кейс с полным циклом и нулём артефактов.

Потребляемый out: acc (t0095) — OUT и вход фазы 3 (lt1). Легально (§5.8).

Стоимость дорог (n = 10, одинаковая финальная сверка):
  for = while напрямую:      49 шагов (4 на итерацию)
  for = range + foldlist:   109 шагов (9 на итерацию)
  переплата 60 шагов — materialization диапазона. Покупка: дедуктивный
  аргумент нужен ОДИН раз (range-билдер), далее структурная терминация
  каждого for. Перенос доказательства из per-case в once-per-library.

Внешний якорь: 1+4+9+16+25+36+49+64+81+100 = 385 — в уме.
Внутренняя кросс-сверка: acc = 385, f = 385, eq = 1 — журнал проверяет сам себя.
