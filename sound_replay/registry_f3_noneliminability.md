# Реестр — F-3.1: неэлиминируемость суммы цифр
# 2026-11-23

Пункт: F-3.1 — классовое различение while vs термов словаря.
Статус: структурный аргумент сформулирован; полная формализация
(определимость в термах над <Z, +, x, div, mod>) — исследовательская,
открыта. Стек не выдаёт недоказанное за доказанное.

Ядро аргумента:
  Единственный доступ к отдельному разряду в каноне — div/mod.
  plus и mul смешивают разряды необратимо. Фиксированный журнал содержит
  конечный бюджет извлечений разряда — терм слеп к старшим разрядам n,
  превосходящим этот бюджет.

Контраст (доказуемо содержательный):
  Цифровой корень — функция n mod 9: закрытая форма есть (кейс (г)).
  Сумма цифр — закрытой формы нет (кейс (д)): while здесь единственная
  дорога, а не обходной путь. Элиминация — пер-кейсный творческий акт
  либо невозможна; систематического метода поиска формы не существует
  (это и есть граница).

Свидетели классового различия:
  операционный смысл: структура журнала фиксирована, число повторений —
  данные (аргумент накачки).
  функциональный смысл: 2^x — примитивно-рекурсивна, не терм; рост терма —
  не быстрее полинома фиксированной степени, оси ширины и глубины ортогональны.

Связь с теорией (не часть канона, культурная заметка):
  словарь без mul — «пресбургеровская» сторона; mul — переход через линию
  разрешимости; bounded while — LOOP-уровень (Мейер–Ричи), класс PR.
