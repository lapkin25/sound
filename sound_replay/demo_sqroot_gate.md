Предсказание (до прогона):
  формула: шагов = 9 + 4k, k — число итераций Ньютона
    (2 константы + 4 шага на итерацию: div, plus, div, lt + 7 финальных шагов)
  трасса в уме: k = 7  =>  37 шагов
  граница (новый орган протокола): k <= 2*ceil(log2 n) + 2 = 20 для n = 472
    обоснование: при x >= sqrt(n) имеем y = (x + n//x)//2 >= sqrt(n) и
    y < x даёт строгое убывание целого x; убывание >= (x - n//x)/2,
    что при x >= 2*sqrt(n) удваивает скорость спуска => логарифмическая граница.

Результат прогона:
  37/37 шагов, ноль расхождений независимого реплея, SSA чист.
  Итераций: 7. Согласие с границей: 7 <= 20 — OK (первая проверка нового органа).
  Шаги = 9 + 4*7 = 37 — предсказание сошлось.
