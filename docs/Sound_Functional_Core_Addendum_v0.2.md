# Sound Functional Core — Addendum v0.2

Аддон к Sound Language Specification v0.1. Вводит функциональное ядро: чистые выражения, вывод типов, встроенные примитивы и чистые узлы.

## 1. Принципы

1. **Полнота по построению**: нет рекурсии (`SC-005`), нет циклов и эффектов. Рантайм-сбои (деление на ноль → `DomainError`) выходят за границу узла как `Err(...)`.
2. **Дефолтизация только на границе**: промежуточные числовые переменные (`numeric`) дефолтизируются к `Int64` лишь в `finalize` на выходе узла; внутри выражения смешение `Int64/Float64` легально.
3. **Сужение — забота границ**: `Float64 → Int64` отсекается на рёбрах графа (SC-040), не внутри унификатора.

## 2. Выражения (грамматика)

    expr   = let | fun | if | or ;
    let    = "let" IDENT "=" expr "in" expr ;
    fun    = "fun" IDENT { IDENT } "->" expr ;       (* каррирование *)
    if     = "if" expr "then" expr "else" expr ;
    or     = and { "or" and } ;  and = cmp { "and" cmp } ;
    cmp    = add [ ("=="|"!="|"<"|"<="|">"|">=") add ] ;
    add    = mul { ("+"|"-") mul } ;  mul = unary { ("*"|"/") unary } ;
    unary  = "-" unary | "not" unary | app ;
    app    = atom { atom } ;                          (* аппликация влево *)
    atom   = NAT | FLOAT | "true" | "false" | IDENT
           | "(" expr ")" | "[" expr { (";"|",") expr } "]" ;

Проверка EOF обязательна: лишние лексемы — `SC-098 TrailingTokens`.

## 3. Примитивы

Схемы типов (инстанцируются свежими переменными на каждое использование; частичное применение корректно):

| Примитив | Схема | Замечание |
|---|---|---|
| `map` | `(a→b) → Vector[a,d] → Vector[b,d]` | d — DimVar схемы |
| `reduce` | `(a→e→a) → a → Vector[e,d] → a` | |
| `sum` | `Vector[a,d] → a` | a — числовое ограничение |
| `len` | `Vector[a,d] → Int64` | |
| `not` | `Bool → Bool` | |

`and`/`or` — уровни грамматики (не функции): оба операнда `Bool`.

## 4. Вектор-литералы и R-HET

Сигнатуры элементов собираются **до** унификации: `{Int64, Float64}` смешанные — `SC-060 HeterogeneousMatrix`. Проверка обязана предшествовать склейке ограничений, иначе целочисленный литерал наследует `float`.

## 5. Чистые узлы

`rule f(x: T) -> R = expr;` — узел без внешнего рантайма. Тело выводится и унифицируется с сигнатурой: аргументы — как объявлено, результат — с точным расширением `Int64 → Float64`. SC-001 к чистым узлам не применяется.

## 6. Границы узлов

- Асимметрия расширения/сужения: внутри выражений `int+float → float` легально; на ребре `Float64 → Int64` — SC-040.
- Размерности — строки/целые/dim-переменные; конфликт имён — SC-050 DimConflict.
