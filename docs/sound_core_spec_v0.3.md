# Sound Core (SCore) Specification v0.3

## Цель
SCore — эталонное исчисление и контракт побайтово воспроизводимого журнала исполнения. Любая трансляция SCore-программы обязана давать побайтово одинаковый журнал.

## Значения (шесть сортов)
- Целые — неограниченная точность (эталон: Python int).
- Плавающие — ровно один тип, IEEE-754 double.
- Булевы.
- Векторы — гетерогенные не разрешены; индексация с нуля.
- Замыкания — лексический захват снимка окружения на момент создания.
- Ошибки — значения с кодами (DomainError, PrecisionLoss, TypeMismatch, ...).

## Семантика операций
- `int op int -> int`; операции со смешением или плавающими — через widen в double.
- Деление — всегда float; на ноль — IEEE-семантика (inf/-inf/nan).
- Первая ошибка побеждает: узел с операндом Err передаёт ошибку как значение.
- `widen` (int→float): всегда точен.
- `narrow` (float→int): дробная часть нулевая — OK с событием (lossy: true); ненулевая — Err(PrecisionLoss).
- Reduce — с явным аккумулятором; на пустом векторе возвращает acc без единого шага.
- Лексический скоуп: `let x = 1 in let f = fun y -> x+y in let x = 105 in f 5` даёт `6`.

## ANF
Каждое промежуточное значение получает имя; узлы в топологическом порядке; каждый операнд вычислен к моменту использования. Порядок вычислений задан структурой ANF, а не стратегией бэкенда.

## 7.1 Каноническая сериализация float
Совпадает с `float.hex()` CPython: мантисса добита до 13 шестнадцатеричных цифр; короткий ноль `0x0.0p+0` (со знаком); субнормали `0x0.<13>p-1022` без перенормировки; `inf`, `-inf`, единый `nan`. Формат — часть спеки, не деталь реализации.

## 7.2 Журнал (trace)
События в порядке исполнения ANF-узлов:
- `bind <имя> <канон>` — именованное связывание;
- `coerce <имя> <тег> [lossy:true]` — конверсия;
- `err <имя> Err(<код>)` — в КАЖДОМ именованном связывании, значение которого — ошибка (создана здесь или протекла сверху);
- `result <канон>` — финальное значение.

Контракт: **любая трансляция обязана давать побайтово одинаковый журнал**.

## Статические проверки
Закрытый порядок обнаружения: SC-002 (неопределённое имя) проверяется раньше, чем SC-060-класс (дубли параметров замыканий — отдельный код SC-061; SC-060 сохранён за HeterogeneousMatrix).

## Отклонения
Любое отклонение бэкенда (F32-арифметика, ограниченные целые и т.п.) — только явно, флагом в спеке; трейсы такого бэкенда выпадают из золотого сравнения.
