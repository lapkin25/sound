# SPEC: Трёхслойная система верификации
## «Прямая дорога» / «Sound-машина» / «Mathmachine»

Версия 1.0 · Ноябрь 2025

---

## Архитектура

```
КОД
 │
 ├─▶ [СЛОЙ 0: Прямая дорога]  CFG, циклы, разрезы, тривиальные вердикты
 │        │  очередь сложных мест
 │        ▼
 ├─▶ [СЛОЙ 1: Sound-машина]   инварианты, SAFE / UNSAFE / MAYBE
 │        │  очередь MAYBE с контекстом
 │        ▼
 └─▶ [СЛОЙ 2: Mathmachine]    контрпримеры и доказательства, динамика
```

Общий принцип: слои расположены по нарастанию точности и цены. Статика
(циклы, разрезы, паросочетания) — дёшево, ловит грубое. Динамика (обход
состояний, развёртки) — дорого, ловит тонкое. Порядок фиксирован: каждый
верхний слой работает на очищенной и суженной модели предыдущего.

# SPEC-0: ПРЯМАЯ ДОРОГА (быстрый слой)

## Назначение

Самый дешёвый проход: разобрать программу на граф, найти всё, что видно
«с дороги», и подготовить модель для верхних слоёв.

## Вход

- исходный код (или IR);
- конфигурация проверок.

## Выход

- CFG (граф потока управления) с блоками и рёбрами;
- классификация узлов: ациклические пути, циклы (SCC по Тарьяну),
  хабы-семафоры;
- карта узких мест: разрезы по PR, точки отказа;
- вердикты по тривиальным проверкам: явное деление на ноль, мёртвые ветки,
  нарушенные порядки захвата блокировок;
- очередь «сложных мест» на слой 1.

## Алгоритм

1. Построить CFG; Тарьян — найти SCC и обратные рёбра (циклы).
2. Прогон PR: максимальный поток по ресурсной модели → минимальный разрез
   → список узких мест.
3. Прогон Куна там, где есть парная структура (ресурсы ↔ потребители);
   при дефиците — сертификат Холла.
4. Прямое исполнение ациклических путей: линейные участки считаются честно,
   без приближений — всё, что не в цикле, проверяется точно уже здесь.
5. Всё, что живёт внутри циклов или гонок, — в очередь слоя 1.

## Инварианты корректности

- слой не выдаёт вердиктов SAFE/UNSAFE по циклам — только маршрутизацию;
- ошибка слоя 0 = потеря производительности, не корректности.

## Сложность

- Тарьян: `O(V + E)`;
- PR: `O(V³)`;
- суммарно: линейно-кубично от размера программы.

## Режимы отказа

Программа без явной структуры (не-двудольные пары, нецелые ёмкости) —
слой отдаёт вопрос вверх, не фантазирует.

# SPEC-1: SOUND-МАШИНА (абстрактный слой)

## Назначение

Вывести инварианты по всему CFG и закрыть максимум проверок вердиктами
`SAFE` / `UNSAFE`. Остаток (`MAYBE`) — передать наверх.

## Вход

- CFG от слоя 0;
- абстрактная область `D` (интервалы по умолчанию, настраиваемо):
  `[lo, hi]` для каждой переменной;
- передаточные функции `F_e : D → D` для каждого ребра
  (присваивание — сдвиг границ, условие — сужение, слияние — join);
- оператор расширения `widening`.

## Выход

- `map: узел → инвариант` (после достижения неподвижной точки);
- вердикты по каждой точке проверки: `SAFE` / `MAYBE` / `UNSAFE`;
- для каждого `MAYBE` — контекст: путь, диапазон значений, какая
  передаточная функция загрубелила.

## Алгоритм

1. Инициализация: вход — ограничения, остальное `⊤` («любое значение»).
2. Worklist-итерации: снять узел из очереди, для каждого исходящего ребра
   вычислить `I' = F_e(I[узел])`; если `I' ⊄ I[приёмник]` — обновить и
   пере-поставить приёмник в очередь.
3. На обратных рёбрах цикла — `widening` (гарантия остановки), затем
   опционально `narrowing` для возврата точности.
4. Стоп: очередь пуста = неподвижная точка (наименьшая безопасная
   пере-аппроксимация).
5. Вердикты; `MAYBE`-контексты — в очередь слоя 2.

## Инварианты корректности

- монотонность всех `F_e` (проверяется при загрузке области);
- soundness: конкретные значения в узле ⊆ абстрактного инварианта;
  `SAFE` и `UNSAFE` железны, `MAYBE` — честное «не знаю»;
- остановка гарантирована `widening`'ом (конечная высота решётки или
  срез бесконечных цепочек).

## Сложность

`O(итерации × |E| × стоимость F)`; на интервалах — единицы–десятки
итераций.

## Режимы отказа

- ложные `MAYBE` допустимы и являются нормальным продуктом приближения;
- пропуск реальной ошибки запрещён; возможен только при нарушении
  контракта `F_e` (немонотонность, ошибочная реализация).

# SPEC-2: MATHMACHINE (точный слой)

## Назначение

Взять то, что слои 0–1 не закрыли, и дожать математикой: точные
доказательства там, где приближения сказали «возможно».

## Вход

- очередь `MAYBE`-контекстов от слоя 1 с их инвариантами;
- для параллельных участков — модель взаимодействий (позиции, ожидания,
  ёмкость семафоров).

## Выход

- вердикт по каждому `MAYBE`: либо контрпример (конкретный вход, ведущий
  к ошибке), либо доказательство безопасности;
- для динамики: достижимость тупика, наличие выхода из каждого ожидания;
  при взрыве состояний — развёртка с отсечениями.

## Алгоритм

1. Уточнение `MAYBE`: symbolic execution по помеченному пути с инвариантом
   слоя 1 как ограничением → система условий → решатель. Есть решение →
   контрпример; нет → `SAFE` доказан.
2. Циклы с нелинейностью: узкая итерация (`narrowing`) на точной
   арифметике либо символьный вывод инварианта цикла.
3. Параллельный код: построить сеть, BFS по пространству состояний;
   тупик = состояние без исходящих рёбер, кроме финального. Пространство
   большое → развёртка: события вместо состояний, cutoff-правила отсекают
   эквивалентные ветви; soundness сохраняется, полнота частично
   жертвуется (фиксируется в отчёте).

## Инварианты корректности

- все ответы слоя 2 точны относительно входной модели (контрпример всегда
  воспроизводим на модели);
- soundness наследуется от модели: если модель пере-аппроксимирует
  программу — вердикты железны с той же оговоркой.

## Сложность

Решение условий — от полиномиальной до экспоненциальной; поэтому слой
запускается последним и только на остатке.

## Режимы отказа

- неразрешимые условия → честный «не доказано» (не «безопасно»!);
- развёртка с cutoff может пропустить тупик в отсечённой ветви —
  фиксируется в отчёте.

# Контракты между слоями

1. Слой обязан передавать вверх ВСЁ, что не смог закрыть, — молчание
   запрещено.
2. Каждый верхний слой получает не только вопрос, но и знания нижнего
   (инварианты, пути, разрезы) — они сужают его работу.
3. Вердикт нижнего слоя никогда не пересматривается верхним в сторону
   ослабления: `UNSAFE` остаётся `UNSAFE`; верхний слой может только
   уточнить `MAYBE`.

## Формат обмена (очередь MAYBE-контекста)

```
MAYBE-контекст:
  location:   узел CFG / ребро / точка проверки
  check:      тип проверки (деление, границы, блокировка, deadlock)
  invariant:  инвариант слоя 1 в этой точке
  path:       путь от входа (если ациклический) / позиция в цикле
  blur:       место загрубления (какая F_e / widening)
  hint:       знание слоя 0 (SCC-номер, разрез, паросочетание)
```

## Цепочка soundness (главный инвариант системы)

Каждый слой пере-аппроксимирует программу сверху; пере-аппроксимация
только накапливается, но не исчезает. Если вся система говорит `SAFE` —
это гарантия для всех реальных исполнений программы.

Цена системы — количество `MAYBE`, дошедших до вершины.
Качество — насколько дорогое сведение удаётся сделать на слоях 0–1.
