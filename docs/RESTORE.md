## Что в архиве проверено

- `run_static_checks.py` — ALL CHECKS PASS: баланс скобок (11 файлов),
  символы C/Java/JS, зеркальный смок канона 7.1 (200 018 паттернов, 0 расхождений),
  побитовый roundtrip канонического TRIOMAT1 (6 целевых ловушек + 1000 случайных
  doubles, 0 расхождений), детекция бага column-major/row-major.
- Java `fmtHexDouble` и C `fmt_hex_double` — зеркально проверены против
  `float.hex()` ранее в проекте (1.5M паттернов, 0/0).

## Открытые гейты (не притворяются закрытыми)

1. **Полный гейт C**: `gcc all_terms.c -o t06 && ./t06` → сверка с
   `canonical_trace_T06` из `src_c/manifest.json` побайтово. Нужно 10 минут и gcc.
2. **Полный гейт Java**: `javac src_java/*.java && java -cp src_java TermT06`
   → та же сверка.
3. **Полный гейт JS**: `node src_js/TermT06.js` → та же сверка; затем
   `node tests/test_roundtrip.js` (нужен Octave >= 7) → побитовый roundtrip
   с настоящим Octave. В контейнере нет Node/Octave — гейты остаются OPEN.
4. **Java D-J1**: `long` вместо неограниченных целых — либо BigInteger, либо
   честный флаг отклонения. JS-бэкенд это закрывает через BigInt.
