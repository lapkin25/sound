# Release Notes: Sound v0.3

## Что нового
- Рантайм на C99: типы, операции, замыкания, ошибки, каноническая сериализация.
- Java-рантайм (скелет): SoundValue/Ops с той же семантикой и тем же каноном 7.1.
- Генераторы: c_backend.py (ANF→C99), gen_java.py (ANF→Java, эскиз).
- Единый статический харнесс run_static_checks.py: баланс скобок, символы, зеркальный смок канона — для C и Java.
- Оракул golden_corpus.py + golden_traces.json (в архиве помечены как требующие восстановления, см. RESTORE.md).

## Известные отклонения
- D-J1 / общий: INT хранится как int64/long в C и Java; эталон — неограниченные целые. До BigInteger (или явного флага отклонения) трейсы за пределами 2^63 не сверяются с эталоном.
- Деление на ноль: спека v0.2 обещает Err(DomainError), SCore v0.3 делит по IEEE. Повестка v0.3.1 — выбрать одно до расширения корпуса.

## Планы v0.4
- FFI/glue для моста Trio; замыкания в C-бэкенде без заглушек; полиморфный let, broadcast; переопределяемая звуковая разметка.
