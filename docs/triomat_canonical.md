# Канонический формат TRIOMAT1 (спека моста Trio, раздел 8)

## Компоновка

```
[u32 LE: длина заголовка] [заголовок: UTF-8 JSON, ровно hlen байт] [payload: C-порядок]
```

Заголовок (JSON):

```json
{
  "magic": "TRIOMAT1",
  "dtype": "Float64" | "Int64" | "Bool",
  "shape": [rows, cols],          // массив неотрицательных int; [] = скаляр
  "flags": { "stub": false, "lossy": false, "trusted": true }
}
```

## Payload

- `Float64`: 8 байт на элемент, IEEE-754 LE, row-major (C-порядок)
- `Int64`: 8 байт на элемент, знаковое LE (точно до 2^63-1)
- `Bool`: 1 байт на элемент, только 0 или 1 — всё остальное это Err(BoolPayload),
  а не «истина, если ненулевой»

## Ошибки (закрытый список, ноль эвристик)

| Код | Когда |
|---|---|
| `MalformedHeader` | не UTF-8 JSON, неверный magic |
| `ShapeError` | обрезанный заголовок/payload, лишние байты, отрицательные размерности |
| `TypeError` | dtype вне закрытого списка (Float32 не существует в SCore) |
| `BoolPayload` | байт Bool не равен 0 или 1 |

## Ключевая ловушка Octave

`reshape` в Octave — column-major, payload TRIOMAT — row-major. Корректное чтение:
`reshape(data, cols, rows)'`. Прямое `reshape(data, rows, cols)` даёт
транспонированную матрицу — и на квадратных симметричных (граф смежности!)
проходит незамеченным. Тест нарочно использует неквадратную 2x3.

## Флаги (контракт Trio)

- `lossy` — данные прошли через неограниченные целые (R-INT1: > 2^53 в double)
- `stub` — заглушка вместо реального узла
- `trusted` — false, если источник узла — ResourceLost

Канонизация чисел (-0.0, паттерны NaN) — не работа парсера: парсер сохраняет
биты как прочитаны, канон — только в `canon()` при записи журнала.
