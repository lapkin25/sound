# Sound: язык, который слышно. От декларативной спеки до побайтово одинакового журнала

*(Полная версия поста — в диалоге проекта; здесь — итоговая редакция для репозитория.)*

## Три слоя и один мост

- **v0.1 — Sound как язык спецификаций**: программа описывает, *что* должно быть истинно — факты, правила, инварианты, цели. Компилятор строит граф. Нет циклов, нет `if`, нет присваиваний: порядок выводится из графа данных.
- **v0.2 — функциональное ядро**: *как* считать внутри узлов — чистые выражения `let`/`fun`/`if`, примитивы `map`/`reduce`/`sum`/`len`, вывод типов. Нет рекурсии (SC-005), нет эффектов.
- **v0.3 — SCore**: как *доказать*, что ядро считает одинаково на любом бэкенде — контракт побайтово одинакового журнала.
- **Trio bridge** — среда передачи между рантаймами (Python, Java, Octave) и чистыми узлами: модель конверсий OK / Lossy / Err, закрытый набор TrioError, байтовый формат TRIOMAT.

## Связь слоёв

v0.1 задаёт обещание, Trio переносит данные по контракту, ядро v0.2 даёт общую семантику вычислений, SCore делает её проверяемой — до последнего бита. Замыкание захватывает окружение на момент создания: `let x = 1 in let f = fun y -> x+y in let x = 105 in f 5` даёт `6`, не `105`.

## Контракт журнала

Каждое исполнение пишет события `bind`/`coerce`/`err`/`result` в канонических форматах — вплоть до побитовой записи каждого double (`float.hex()`: мантисса 13 hex-цифр, субнормали без перенормировки). Требование: **любая трансляция даёт побайтово одинаковый журнал**. Проверка — оракул (двойной прогон, побайтовая детерминика), C-бэкенд, зеркальный тест `fmt_hex_double` на 1.5M битовых паттернов: первый вариант содержал баг (маска мантиссы 48 бит вместо 52) — пойман зеркалом, не чтением кода.

## Партитура

Звуковая семантика v0.1 — не украшение: старт узла — нота по рантайму (python A4, java C5, octave E5, pure G4), Lossy — приглушение, ShapeError — тритон, DomainError — малая секунда, ResourceLost — тишина. Партитура, которую нельзя воспроизвести дважды, — не партитура. Партитура требует воспроизводимого журнала — так идея «программа звучит» из v0.1 оказалась скрытой мотивацией контракта v0.3.

## Состояние

- Статический рубеж C99 и Java: PASS (единый харнесс, `ALL CHECKS PASS`).
- Зеркальный тест канона 7.1: 0 расхождений у обеих реализаций.
- Полный гейт (gcc/javac + побайтовая сверка): **OPEN** — см. RESTORE.md.
- Общее отклонение D-J1: INT — int64/long в бэкендах против неограниченных в эталоне.
- Спорное: деление на ноль (IEEE в v0.3 против Err(DomainError) в v0.2) — повестка v0.3.1.
