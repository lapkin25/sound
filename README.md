# Sound v0.3 — прототип декларативного языка для распределённых моделей

Sound описывает, что должно быть истинно; компилятор строит граф; функциональное ядро
считает чистые узлы; SCore гарантирует побайтово одинаковый журнал на любом бэкенде.
Каждый прогон звучит: партитура из событий — лицо детерминизма.

## Состав
- docs/ — спеки: язык v0.1, ядро v0.2, SCore v0.3, мост Trio v0.1; релиз; пост-объяснение.
- src_c/ — рантайм C99 (каркас) и автогенерируемый all_terms.c.
- src_java/ — рантайм Java (SoundValue, Ops) и сгенерированный TermT06.
- tools/ — c_backend.py (ANF→C99), gen_java.py (ANF→Java), run_golden_c.py (полный гейт),
  run_static_checks.py (статический рубеж + зеркальный тест канона 7.1).
- RESTORE.md — честный список утраченных файлов предыдущей сессии.

## Быстрый старт
    python3 tools/run_static_checks.py   # статический рубеж: ALL CHECKS PASS
    python3 tools/run_golden_c.py        # полный гейт: требует gcc/javac и golden_traces.json (см. RESTORE.md)
