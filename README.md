Sound — декларативная система программирования, где каждый прогон звучит. Вы описываете, что должно быть истинно, а компилятор строит граф вычислений. Функциональное ядро считает чистые узлы, а слой SCore гарантирует побайтово одинаковый журнал (trace) на любом бэкенде. Детерминизм здесь — это воспроизводимость до последнего бита.
