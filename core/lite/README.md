# Trio / Sound

Прототип полиглот-конвейера с декларативной спецификацией и аудио-отладкой.

Три слоя:

```
AnomalyMonitor.sound        <- декларативная спека (Sound Language Spec v0.1)
        |
sound_compiler.py           <- компилятор: спека -> граф Trio -> партитура
        |
pipeline_graph.json         <- граф Trio: узлы, рёбра, режимы, инварианты
        |
executor.py                 <- исполнитель: запуск узлов, TRIOMAT, живой звук
        |
trio_bridge.py / TrioBridge.java / trio_bridge.m   <- граница трёх рантаймов
```

## Что это

- **Sound** — язык спецификаций: факты, правила, инварианты, цели. Без циклов и `if`.
  Компилятор строит граф Trio и проверяет программу до запуска.
- **Trio** — исполнительная среда: типизированный граф вычислений поверх трёх
  рантаймов (Python, Java, Octave) с общими типами на стыках.
- **TRIOMAT** — бинарный формат обмена матрицами между рантаймами: заголовок
  big-endian, payload little-endian, layout в заголовке.
- **Партитура** — звуковое представление исполнения: старт узла — нота по
  рантайму, Lossy на ребре — приглушение, ошибка — диссонанс, ResourceLost — обрыв.

## Быстрый старт

```bash
# 1. Компиляция спеки
python sound_compiler.py pipeline.sound
# -> pipeline_graph.json, score.wav

# 2. Сборка Java-бриджа (если есть JDK)
javac TrioBridge.java TrioBridgeTest.java
java TrioBridgeTest          # 27 проверок

# 3. Прогон графа
python executor.py pipeline_graph.json
# -> живая партитура по событиям рантайма
```

## Структура репозитория

| Файл | Назначение |
|---|---|
| `sound_spec_v0.1.md` | спецификация языка Sound |
| `trio_spec_v0.1.md` | спецификация Trio: типы, правила конверсий, TRIOMAT |
| `sound_compiler.py` | компилятор Sound: парсер, унификация, диагностики SC-* |
| `executor.py` | исполнитель графа: узлы, рёбра, живая партитура |
| `trio_bridge.py` | Python-эталон бриджа (37 проверок) |
| `TrioBridge.java`, `TrioBridgeTest.java` | JVM-сторона (27 проверок) |
| `trio_bridge.m` | Octave-сторона |
| `pipeline.sound` | пример спеки AnomalyMonitor |

## Статус

Исследовательский прототип, не продукт. Известные ограничения: один вход на узел,
упрощённая топологическая сортировка, view эмулируется копированием, партитура —
статическая в компиляторе и живая только в исполнителе.

## Авторство

архитектурные решения — авторы проекта. Лицензия — на усмотрение автора.
