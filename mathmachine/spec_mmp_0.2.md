# Спека конвейера Math Machine — v0.2 (MM-3)

Фундамент: четыре закрытых строки факт-ряда (fact(5), add(6,7), mul(6,7), mul8),
живые протоколы 110/135/933/1336 записей, регрессионный кейс mul.pr.

## 1. Контракт `args` по опкодам

| Опкод | args в протоколе | Примечание |
|---|---|---|
| PUSH n | [] | значение — не протоколируется отдельно, читается из state.V на следующей записи |
| LOAD i / STORE i | [] | индекс слота в инструкции, не в протоколе |
| ADD/SUB/MUL | [] | V после операции — в state.V этой же записи |
| JZ метка | [тест] | единственный опкод с данными в args вне CALL/RET |
| JMP метка | [] | |
| CALL [fn, n] | [a1..an] | снятые со стека аргументы |
| RET | [v] | возвращаемое V |
| HALT | [] | финальная запись, V = результат |

Доказательная база: несоответствие хотя бы одного пункта — тикет на протокол.

## 2. Правило молчаливых этапов

Каждый этап конвейера обязан валидировать вход ДО выдачи артефакта.
Сводка «записано: ...» не может появиться для семантически неверной программы.

Реализация: патч pr2sound v0.3.2 (семантический барьер в compile_program,
до кодогенерации): collect_vars тела каждой функции, entry-имя, литералы entry.
Регресс-кейсы, обязанные падать:
  - mul.pr: свободное имя 'a' в теле h -> NameError с текстом про параметры;
  - entry с переменной в аргументах.

## 3. Мёртвый параметр (граница выразительности)

mul(a, b) = prec(b, 0, h) с литеральным h вычисляет b x L, параметр a не читается.
Живая иллюстрация: mul6.pr (7x6=42, совпало с 6x7) vs mul8.pr (8x8=64, не 6x8).
Статус: НЕ баг, а ограничение языка — без замыканий настоящий mul(a,b)
не выразим. Снимается пунктом 4.

## 4. Расширение языка: статический лямбда-лифтинг prec-шага

Свободные переменные тела prec-шага поднимаются в его параметры;
на месте CALL шага передаются значения из области определения (слоты вызывающей
функции). Пример:
  def h(k, acc) = add(acc, a)   ->   def h(k, acc, a) = add(acc, a),
  CALL из mul передаёт LOAD слота 'a'.
С этим расширением: настоящий mul(a, b) выразим, и целевая программа MM-3 —
  def h2(n, acc) = mul(n, succ(acc))
  def fact(n) = prec(n, 1, h2)
факториал, где умножение — наша же программа из сложения: граф вызовов
глубины 5, вся арифметика конвейера собрана из самого конвейера.

## Приложения

Модели, подтверждённые на всех точках:
- тариф прямой дороги: T = n*(iter + succ + ops), пользовательские вызовы бесплатны;
  подтверждён: fact 15, add 14, mul6 91, mul8 136 (осознанно на трёх точках).
- машина: add(~, b) = 17b+12 записей; mul(L, b) = b*(17L+29) + 16;
  подтверждён: 933, 1064, 1336.
- Уроки журнала: совпадение на неразличающих случаях не подтверждение;
  прогноз пересчитывается от программы, а не копируется от соседней строки;
  исходник этапа — тоже данные.
