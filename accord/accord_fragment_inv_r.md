# accord.md — фрагмент для внесения (раздел «Носитель»)

## Инвариант носителя: линейность реплея

**ИНВ-Р (реплей строго линеен).** Журнал — линейная развёртка ациклического графа. Исполнение
журнала любой платформой — один прямой проход без возвратов и передач управления; каждый узел
вычисляется ровно один раз. Ветвление существует только в значениях: `If` выбирает одно из двух
*уже вычисленных* значений и не передаёт управление.

Из ИНВ-Р следуют четыре обязательных свойства, каждое с проверяемым следствием:

1. **Ссылка всегда назад.** Шаг журнала может ссылаться только на узлы с меньшим номером.
   Ссылка вперёд или на самого себя — дефект транскриптора, а не программы. Проверка обязана
   стоять в валидаторе первым проходом.
2. **Локализация ошибки.** MISMATCH на шаге `t_k` достаточен для вердикта: до `t_k` журнал и
   дублёр уже сошлись, дальше расход не имеет значения. Дублёр обязан остановиться после первого
   расхождения — продолжение исполнения плодит вторичные сообщения.
3. **Отпечаток — функция входа.** Каноническая нумерация фиксирует порядок вычислений полностью;
   недетерминированных источников у журнала нет. Отпечаток вычисляется на стороне мастера ровно
   один раз и не пересчитывается дублёрами.
4. **Итерация — только как явный проход.** Повторное вычисление отсутствует; всё, что в классике
   называется циклом, выражается новыми явными проходами в программе (`foldlist`, их композиция,
   N проходов релаксации). Цикл под капотом носителя недопустим: его наличие в дублёре — дефект.

**Запрещено ИНВ-Р:** обратные ссылки; ленивые и повторные вычисления узлов; мутабельность значений
после вычисления (запись возможна только в хэндлы, читаются они по правилам sound-0.5.1).

**Не запрещено:** произвольное чтение данных (`part` доступен в любой момент — модель не
стриминговая); множественные проходы по одним данным в *программе* — при условии, что каждый
проход порождает собственные узлы журнала и дедупликация между ними не ослабляет sound-0.5.1.

**Уточнение (по прогону DemoRanges, 2026-11-22).** Журнал фиксирует исполнение на данном входе;
отсечение неисполненных чистых ветвей (смоук: строгий `If` вычисляет обе ветви, см. находку
«раздувание журнала», ~5× на DemoRanges) не меняет значений шагов и потому допустимо.

**Где инвариант напряжён.** Единственное место, где модель выпускает читателя за пределы
линейности, — рекурсия под Аккордом (R4): завершение доказывается мерой, и журнал рекурсивной
развёртки обязан оставаться линейным после развёртки. Проверка: транскриптор, порождающий
рекурсивный трейс, обязан предъявить линейный журнал до Аккорда, а не декларировать меру.

**Статус проверки.** Прогон DemoRanges (2026-11-22): три снапшота
("1-3, 5, 9-10" / "1-, 5" / "9-5") — MATCH, 0 нарушений п.1; контрольный слом t1→t500 —
193 висячие ссылки, первая на строке 8; ранний выход подтверждён (остановка на строке 471 из 1186).
Формулировка внесена без изменений к тексту прогона; к ней — два кандидата d2 (см. реестр).
