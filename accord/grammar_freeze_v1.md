# Grammar-freeze v1: связка bind + кортежные литералы

Версия спецификации: **sound-0.5.1**
Дата: 2026-11-23

## 1. Что замораживается

### 1.1 Кортежные литералы

Синтаксис: `(e1, e2, ..., ek)`, k >= 2, компоненты — выражения.
Вложенность допустима: `((a, b), c)` — кортеж из кортежа и скаляра.

Кортеж — первоклассное значение: строится конструктором, читается `part`
по позиции. Семантика узла журнала — конструктор кортежа, порождающий
значение из вычисленных компонент (component-reads поверх него — чистые
узлы `part`, дедуплицируются по sound-0.5.1).

Замораживается: построение и позиционное чтение.
**Не замораживается** (резерв, без обратной совместимости):
- равенство/сравнение кортежей как скалярные операции;
- именованные поля (записи) — кандидат d3, позиционность bind осознанно
  принята как меньший брат;
- образцы в аргументах правил (pattern matching в заголовке).

### 1.2 bind-деструктуризация

Синтаксис: `bind (x1, ..., xk) = expr` — не более одного на правило,
в начале тела правила. Имена уникальны внутри правила.

Семантика: чистый сахар, нулевая стоимость в журнале.

**Правило раскрытия (обязательное для транскриптора):** bind-объявление
не порождает узлов. Имя — локальный псевдоним компоненты; узел
`part expr k` создаётся лениво — в точке первого текстового вхождения
имени, не в точке bind. Неиспользованные имена не материализуются вовсе.

Следствие (приёмочный критерий): журнал bind-версии программы обязан
совпадать **байт-в-байт** с журналом явной версии (`part` на каждом
вхождении). Это делает sugar невидимым для реплееров, отпечатка и ИНВ-Р
— тривиально, так как разницы в журнале нет вообще.

### 1.3 Порядок и каноничность

Порядок part-узлов от bind-имён — порядок первого вхождения, как и для
явных `part`. Каноническая нумерация sound-0.5.1 не меняется.

## 2. Обоснование заморозки

- Три кейса уже используют кортежные аккумуляторы: DemoRanges (6 компонент),
  DemoTM (кортеж мер), DemoMaze (аккумуляторы волны). Без bind читаемость
  катастрофична: позиционные индексы 0–5 повторяются десятками раз,
  перестановка компонент ломает программу неуловимо для статической проверки.
- Словарю связка не добавляет ничего: `part` есть, цена O(1) зафиксирована
  (d2-4, spec_d2-1_setv.md п. 4).
- Цена заморозки — необратимость синтаксиса; резерв явно очерчен (1.1).

## 3. Приёмочный тест

До принятия парсером: транскрипция DemoRanges в двух вариантах —
явном (`part` на каждом вхождении) и bind-версии — обязана дать
идентичные журналы. Эталон: DemoRanges.score
(отпечаток `37cc5a53...`). Тест замыкает сахар на эталон корпуса.

## 4. Статус

- bind + кортежные литералы: **frozen v0.5.1** — из списка grammar-freeze
  кандидатов сняты, переводятся в замороженную грамматику.
- Реестр d2 затронут частично: d2-4 (цена part = O(1)) отсылается из п. 2.
- Не заморожено и перенесено в будущие реестры: записи/именованные поля (d3),
  равенство кортежей (требует обоснования по sound-0.5.1: чтение хэндлов
  не дедуплицируется, а сравнение кортежей — потенциальный канал скрытых
  зависимостей от репрезентации).
