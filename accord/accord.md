# Аккорд — обязательства завершимости и язык мер v1

Версия спецификации: **sound-0.5.1**

## 1. Назначение

Аккорд — свод обязательств по доказательству завершимости рекурсивных правил
Piano. Делает остановку принудительной: рекурсия без меры не компилируется.
Каждое рекурсивное ребро — струна; правило звучит, только когда все струны
убывают согласованно: строго на каждом вызове, не «в среднем».

Следствия: рекурсия не может зациклиться; каждый подслед конечен; журнал конечен;
отпечаток определён. Проверка живёт до исполнения — проваленное обязательство
не может «случиться в рантайме».

## 2. Язык мер v1

- **Кортеж 2–4 компонент** — лексикографическое убывание (обязательство ЧМ2;
  взаимная рекурсия — ЧМ3). Компоненты — выражения из параметров правила.
- **Структурная мера `len[p]`** — длина списка; домен N_0, well-founded.
  Именно она закрыла счётчики Минского и ленту ТМ.
- Оба домена — N_0; теорема: проверенное правило завершается.
- Мера — статическое знание: не создаёт узлов, не входит в отпечаток.

## 3. Правила обязательств

| Правило | Содержание | Статус |
|---|---|---|
| R1 | строгое убывание меры на каждом рекурсивном ребре | зафиксировано |
| R2 | компоненты меры — из well-founded доменов | зафиксировано |
| R3 | структурная мера `len[p]` | зафиксировано (DemoMinsky) |
| R4 | перенос ограничений из гварда ветки (убывание меры и границы `part`) | **черновик** — DemoMinsky: `part[c, 1]` динамически безопасна, статически пока не доказана; эталон намечен |
| R5 | лексикографический кортеж | зафиксировано (DemoTM) |

## 4. Трейсы, зафиксировавшие язык мер

| Трейс | Мера | Отпечаток |
|---|---|---|
| DemoMinsky | `len[c]` (R3) | `4c1ba38e...f9e7d2b4` |
| DemoTM | `(steps, len[l])` — кортеж, R1+R5 | `91d4a7c2...e9f1d6b3` |
| DemoMarkov | не требуется | `e8b2f4c6...a1d3b5c7` |

## 5. Побочный вывод: язык мер потянул словарь

Без операций над списками счётчики и ленты не выражаемы => в core/3-d1 вошли
`tail` и `len`. Core/2 остался замороженным и нетронутым; трейсы объявляют
`dict: core/3-d1`, реплей старой версии их не принимает.

## 6. Находка по Маркову

Правилам алгорифма Аккорд не нужен вообще: они нерекурсивны, двигатель цикла
принадлежит `foldlist`, тотальному по построению. Следствия:

- ограниченный алгорифм вкладывается без обязательств;
- неограниченный — невыразим по построению;
- различие «остановился сам» vs «исчерпал границу» проверяется инвариантом, не Аккордом.

## 7. Родословная и честные пределы

Приём — классическая индукция по well-founded порядку (termination-checker'ы
Agda/Coq). Наш вклад: обязательство обязательно (язык не позволяет рекурсию
без меры) и цена провала — «снапшот не будет выдан».

Предел: Sound строго включён в тотально вычислимые, но не всякая тотальная
функция имеет меру на нашем языке мер. Расширение языка мер расширяет класс
выражаемых программ без выхода из тотальности.

## 8. Цены

`snoc`/`tail` — O(n) на операцию; для ТМ это O(n) на шаг ленты против O(1)
классики — константа, не вычислимость.

## 9. Инвариант носителя: линейность реплея (ИНВ-Р)

**ИНВ-Р (реплей строго линеен).** Журнал — линейная развёртка ациклического
графа. Исполнение журнала любой платформой — один прямой проход без возвратов
и передач управления; каждый узел вычисляется ровно один раз. Ветвление
существует только в значениях: `If` выбирает одно из двух *уже вычисленных*
значений и не передаёт управление.

Из ИНВ-Р следуют четыре обязательных свойства, каждое с проверяемым следствием:

1. **Ссылка всегда назад.** Шаг журнала может ссылаться только на узлы
   с меньшим номером. Ссылка вперёд или на самого себя — дефект транскриптора,
   а не программы. Проверка тривиальна и обязана стоять в валидаторе первым
   проходом.
2. **Локализация ошибки.** MISMATCH на шаге `t_k` достаточен для вердикта:
   до `t_k` журнал и дублёр уже сошлись, дальше расход не имеет значения.
   Дублёр не обязан продолжать исполнение после первого расхождения — и не
   должен, чтобы не плодить вторичные сообщения.
3. **Отпечаток — функция входа.** Каноническая нумерация фиксирует порядок
   вычислений полностью; недетерминированных источников у журнала нет.
   Отсюда: отпечаток вычисляется на стороне мастера ровно один раз и не
   пересчитывается дублёрами.
4. **Итерация — только как явный проход.** Повторное вычисление отсутствует;
   всё, что в классике называется циклом, выражается новыми явными проходами
   в программе (`foldlist`, их композиция, N проходов релаксации). Цикл под
   капотом носителя недопустим: его наличие в дублёре — дефект.

**Что ИНВ-Р запрещает, а что не запрещает.** Запрещает: обратные ссылки,
ленивые и повторные вычисления узлов, мутабельность значений после вычисления
(запись возможна только в хэндлы, читаются они по правилам sound-0.5.1).
Не запрещает: произвольное чтение данных (`part` доступен в любой момент —
модель не стриминговая) и множественные проходы по одним данным в *программе*
— при условии, что каждый проход порождает собственные узлы журнала и
дедупликация между ними не ослабляет sound-0.5.1.

**Связь с обязательствами Аккорда.** Следствие из сек. 1 «журнал конечен»
дополняется здесь условием *линейности*: конечность отвечает на вопрос
«закончится ли журнал», ИНВ-Р — на вопрос «как он устроен, пока не кончился».
Оба свойства проверяются до исполнения и независимы.

**Где инвариант напряжён.** Единственное место, где модель выпускает читателя
за пределы линейности, — рекурсия под Аккордом (R4, черновик): там завершение
доказывается мерой, и журнал рекурсивной развёртки обязан оставаться линейным
после развёртки. Зафиксировано отдельной проверкой: транскриптор, порождающий
рекурсивный трейс, обязан предъявить линейный журнал до Аккорда, а не
декларировать меру.

**Уточнение об отсечении ветвей.** Журнал фиксирует исполнение на данном
входе; отсечение неисполненных чистых ветвей не меняет значений шагов и потому
допустимо. Уточнение внесено по итогам прогона DemoRanges (22.11.2026):
без отсечения журнал автомата разбора диапазонов вырос до 1179 шагов на
входе из 12 символов — строгий `If` вычисляет обе ветви; отсечение даёт
оценку сжатия ~5×. Статус: кандидат d2-3 (реестр d2_candidates.md).
