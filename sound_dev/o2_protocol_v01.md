# О.2 — Протокол отпечатка (черновик v0.1 → обновлён после реверса)

Дата: 2026-11-23. Статус: черновик, решения Q1–Q3 на арбитраже.

## Решённое

**Q4 — закрыто фактурой.** Полный отпечаток DemoSum существует:
`721b9d5c597249d6aec7866090b10306da9cc9944898aac126b0d1149fbd800d` (64 hex).
Ранний обрезок — артефакт заметок, не формата. Реверс по 1262 кандидатам
функцию не восстановил (см. o2_reverse_log.md) — ведущая гипотеза: отпечаток
считается над исходником программы либо над нормализацией, не покрытой перебором.

## Открытые пункты — на слово арбитра

**Q1 — алгоритм.** Рекомендация: SHA-256 (длина сходится: 64 hex).
Доказательной силы у рекомендации нет — длина не отличает SHA-256 от SHA3-256/BLAKE2s.

**Q2 — скоуп байтов.** Рекомендация: S1 — полный файл журнала, LF, UTF-8,
включая заголовок с самим отпечатком (проблемы круга нет: отпечаток вписывается
после вычисления, повторное вычисление по вычисленному полю не выполняется —
при проверке поле заголовка маскируется нулями).
Альтернатива: хеш только тела шагов.

**Q3 — обязательность.** Рекомендация: обязательна для всех журналов нового
контурa (маркер формата >= sound-0.5.3). Легаси-эталоны (DemoSum) — вне протокола.

## Классификация DemoSum при принятии рекомендаций

`легаси, отпечаток вне протокола, функция не восстановлена` — строка сохраняется
в реестре как фактура, верифицируемость честно помечена недостижимой до
появления исходника demo_sum.sound.

## Бэкфилл при принятии рекомендаций

Отпечатки по протоколу выдаются: DemoMax, DemoReverse (журнал и эмит-симуляция),
DemoReverse2 (исправленный), DemoBin2Dec (0.5.1 и 0.5.2), DemoDivMod.
