# Реестр грамматики sound — дельта О.3
# дата: 2026-11-23, статус: О.3 закрыт решением арбитра

## Решение арбитра (запись v0.5.3)

Вердикт: секции `fact` и `out` легализованы.

- `fact имя = выражение` — нематериализующий факт: узел AST, не порождающий
  шаг журнала, пока факт не употреблён выражением. Подтверждено эталоном
  DemoMax (байт-в-байт) и кейсом DemoBin2Dec (unused факт `n = 6` молчит —
  правило «шаг на узел AST» не нарушено).
- `out имя = выражение` — именованный результат; узел, чьё значение попадает
  в финал журнала как результат программы. Шаг порождается самим выражением;
  `out` не добавляет отдельного шага.
- Обе секции каноничны для эры sound-0.5.x начиная с v0.5.3-записи реестра;
  фактическое подтверждение — эталоны DemoMax, DemoBin2Dec, DemoDivMod.

## Легаси-пометка

`section имя ... end` — легаси-форма эры DemoSum. Не запрещена, не перенесена
в текущую эру; новые исходники её не используют. Файл-носитель: DemoSum.journal
(легаси, отпечаток вне протокола О.2 — подтверждено контрольной проверкой).

## Следствия

- Слой F-1 (spec/fact/wire) разблокирован: приёмка парсера полностью зелёная.
- Живых открытых пунктов после О.3: О.5 (независимость self-referential
  эталонов; второй контур — 0.5.2-прогон DemoBin2Dec — уже в деле).
- Легаси-форма DemoSum (явные хендлы-назначения, два пространства имён s/h,
  инлайновый индекс в part, триоперандный plus) — материал для F-1.
