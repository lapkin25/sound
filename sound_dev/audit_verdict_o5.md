# Вердикт human-аудита DemoDivMod — О.5, аудит-лист v01

Дата: 2026-11-23. Аудитор: арбитр (human). Подготовка листа: контур эмиттера.

## Вердикты по пунктам

- **A (ref/len): закрыт.** Обе операции вычислимы из журнала без эмиттера
  (`ref` переписывает значение опорного узла, `len` считается по показанному
  списку). Отсутствие `ref`/`len` в журналах 0.5.2 — канонично; присутствие
  было бы нарушением. В легаси-журнале DemoMax все восемь шагов `ref`/`len`
  проверяются глазами.
- **B (старшие нули): НЕ СОГЛАСЕН арбитра.** Семантика F-2 пересмотрена:
  канонический вывод разложения — без старших нулей. Значимость позиции:
  позиция 10^k значима, если div n 10^k > 0; единицы значимы всегда.
  Реализация — guard-конструкция на if, словарь не меняется.
- **C (дубликаты const 10): закрыт.** Повтор литерала — три узла AST, честный
  дубликат. Нарушение ИНВ-Р.1 — только повторное вычисление одного tid;
  различие проходит по идентификатору, а не по значению.
- **D (порядок цифр): подтверждён.** Старшие первыми.

## Последствия

- `demo_divmod` (v1) и `demo_pipeline` (v1) — superseded by arbiter verdict B;
  перегон в v2 с guard-конструкцией значимости. Старые журналы сохраняются в
  истории с пометкой; их отпечатки остаются верными для своих байтов.
- DemoDivMod v1: статус human-verified по шагам, с пометкой superseded
  (разрядная часть).
- **Запись в О.5:** первый случай, когда human-аудит изменил семантику стека.
  До аудита проверка шла против понимания спецификации тем же контуром, что и
  реализация; независимый вердикт вскрыл расхождение. Опора О.5 работает.
- **Дельта ИНВ-Р.1 (из перегона v2):** запрет касается повторного ВЫЧИСЛЕНИЯ
  узла. Потребление одного узла в нескольких аргументах одного шага легально
  (шаблон Horner-удвоения `plus a a`) — подтверждено журналом v2.
- **Заметка перегона:** Horner-ядро v1 несло перестраховочный if на нулевой
  бит (9 шагов на итерацию); математически лишнее — `plus (plus acc acc) bit`
  корректен и при bit = 0. v2 пишет чистую форму: 4 шага на итерацию, журнал
  сжался с 82 до 55 шагов без изменения семантики Горнера.
