## Скелет итерации (фактура эталона)
    ref <список-операнд> -> ?     ; ссылка на один и тот же список каждый раз
    const <i> -> ?                ; бегущий индекс 0..L-1
    part <ref> <ref-idx> -> ?     ; элемент
    <шаги тела>                   ; acc <- хендл if
Итого 3 шага скелета, НЕ 5: tail-цепочки нет, второго ref нет.

## Подтверждённые решения канона
1. Индекс — по ref (const-шаг + part ref idx): совпадает с DemoReverse, опровергает легаси DemoSum (литеральный индекс).
2. Бегущий индекс по фиксированному операнду: индексы 0..6, список-операнд вычислен один раз (t0022) и переиспользуется.
3. ref на каждую итерацию обязателен; многократные ref на один список — легальны и каноничны (закрыт открытый пункт §9.3).
4. len — один шаг, от списка-базы (не от операнда tail), только для foldlist (DemoReverse len не содержит).
5. Порядок эмиссии: сборка списка -> len -> ref -> якорь-выражение -> выражение списка-операнда -> итерации.
6. Якорь — развёрнутое выражение (part arr8 0), не литерал: ref, const 0, part.
7. Аргументы if: if c then else, c != 0 -> then. Подтверждено правилом step = If (lt cur x) x cur: журнал даёт if t lt-хендл x-хендл acc-хендл.
8. Строгость If: обе ветви — уже вычисленные хендлы, if — один шаг выбора. Мёртвые ветви не вычищаются.
9. Цепочка аккумулятора: тело итерации k ссылается на последний шаг тела итерации k-1. Подтверждено.
10. Заголовочный блок из трёх комментариев присутствует — поддерживает предложение v0.6.1 (заголовок эталона — часть формата).
