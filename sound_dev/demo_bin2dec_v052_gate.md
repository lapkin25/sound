# Протокол ворот: DemoBin2Dec @ sound-0.5.2
Дата: 2026-11-23. Статус: ЗЕЛЁНЫЙ.

## 1. Предмет
Проверка гипотезы О.1 (deref-канон по эра-маркеру) сильным прогоном: DemoBin2Dec
эмитируется в эре sound-0.5.2 без единой правки кода эмиттера — применяется только
канон deref (spec_deref_v01) по маркеру: `ref` перед `part` снят, `len` снят.

## 2. Предсказание и факт
- Предсказание (сделано до прогона): 68 шагов = 13 (сборка bits) + 1 (якорь) + 6 x 9
  (итерация: const idx, part напрямую + тело из 7 шагов).
- Факт: ровно 68. Предсказание сошлось точно.

## 3. Прогон
- Реплей по тексту журнала: 68/68 значений, ноль расхождений.
- ИНВ-Р.1: ноль нарушений, все ссылки строго назад.
- Значения итераций: 1, 2, 5, 11, 22, 45 — совпадают с 0.5.1-прогоном посимвольно
  и с независимым пересчётом по схеме Горнера.
- Финал t0068 = 45 — идентичен финалу 0.5.1-журнала (t0075 = 45).

## 4. Эмиттер
Правок кода эмиттера: 0. Изменение поведения полностью обусловлено deref-каноном
по эра-маркеру (spec_deref_v01, закрыт арбитражем от 2026-11-22).

## 5. Топология
- В журнале 0.5.2: операций `ref` — 0, операций `len` — 0 (прямой поиск по тексту).
- Потребители корня bits (t0013): 6 — все `part` напрямую (в 0.5.1 было 7: len + 6 ref).
- Мёртвые узлы: 0 (корень out не считаем). В 0.5.1 их было 1 сверх корня: t0014 (len).

## 6. Статус гипотез
- О.1 (deref по эре): ПРИНЯТА -> ПРОВЕРЕНА. Два журнала одной программы в двух эрах
  согласованы по значениям; счёт шагов совпал с предсказанием без подгонки.
- О.5 (независимость DemoBin2Dec): частично. Кросс-проверка двух журналов между
  собой — новый контур; но оба построены одним эмиттером, полный внешний якорь
  по-прежнему один (значение 45).

## 7. Рекомендация
Зафиксировать в реестре: О.1 -> проверена; журнал demo_bin2dec_v052.journal —
эталон кейса с пометкой self-referential (наследует О.5).
