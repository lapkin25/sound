# Спецификация deref-канона — v0.1 (sound-0.5.1 / sound-0.5.2)

Статус: принят арбитром 2026-11-23. Основание: DemoMax, DemoReverse (0.5.1),
DemoReverse2 (0.5.2), кейс DemoBin2Dec (0.5.1-ветка).

## Правило

Маркер формата в заголовке журнала определяет два аспекта скелета:

| Аспект                        | sound-0.5.1 | sound-0.5.2 |
|-------------------------------|-------------|-------------|
| ref перед каждым part         | да          | нет         |
| len в скелете foldlist        | да          | нет         |
| part от вычисляемого операнда | через ref   | через ref   |

«Вычисляемый операнд» — операнд списка, не являющийся прямым data-именем
(например, `tail arr8`). Для вычисляемых операндов ref ставится в обеих эрах.
