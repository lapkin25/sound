## 0. Что проверять и по каким определениям

Определения канона (словарь v0.5.3, deref-канон 0.5.2):

- `const c` -> значение c. Шаг на каждый литерал.
- `div a b` -> усечённое целое деление a/b (в сторону нуля).
  Деление на 0 — ошибка реплея (в журнале не встречается).
- `mod a b` -> остаток по тождеству a = (a div b)*b + (a mod b),
  знак по делимому.
- `snoc lst x` -> список lst с x, добавленным В КОНЕЦ.
- deref-канон 0.5.2: операнды-значения идут в операцию напрямую,
  без `ref`; `len` не порождается.

Исходник (demo_divmod.sound):

    fact n = 45
    out digits = snoc (snoc (snoc nil (mod (div n 100) 10))
                            (mod (div n 10) 10))
                            (mod n 10)

Внешний якорь: 45, разложение [0, 4, 5] — проверимо устным счётом.
