# Спецификация Sound (v0.6 draft)

Составлено по состоянию кода `run_pr.py` (v0.1 draft) и протокола обсуждения.
Разделы помечены: **[код]** — подтверждено реализацией и прогоном;
**[разговор]** — зафиксировано в обсуждении, реализации пока нет;
**[открыто]** — требует решения.

## 1. Назначение и общая схема

Sound — система двойной (независимой) верификации вычислений:
программа на примитивной рекурсии исполняется двумя дорогами:

1. **Прямая дорога** — `run_pr.py`: интерпретатор схем PR, считает
   «прямую» метрику шагов. **[код]**
2. **Звуковая дорога** — `pr2sound.py` + `run_sound.py`: трансляция
   определений в программу звук-слоя, исполнение на MathMachine
   (ленты-счётчики), счёт машинных шагов. **[разговор]** — файлов нет.

Сопоставление дорог — по значению результата. Метрики шагов дорог
**не обязаны совпадать** (прямая метрика ≠ машинные шаги). **[код, разговор]**

## 2. Синтаксис .pr **[код]**

    def <имя> = <выражение>
    ...
    entry <имя>(<целые через запятую>)

Выражения:

- `z` — нулевая функция;
- `s` или `s(expr)` — функция следования (вторая форма — сахар);
- `pi(k, i)` — проекция, требуется `1 <= i <= k`;
- `comp[f, g1, ..., gm]` — композиция;
- `prec[g, h]` — примитивная рекурсия;
- `(expr)` — группировка;
- `имя` — ссылка на def или атом словаря.

Комментарии: от `#` до конца строки. Имена: `[A-Za-z_]\w*`.
Повторный `def` того же имени — ошибка.

## 3. Конвенция prec **[код — подтверждена прогоном]**

Счётчик добавляется **первым** аргументом:

- база: `g` применяется к `(0, x)`;
- шаг: `h` применяется к `(j, v, x)`, где `j = 0..n-1` — номер итерации,
  `v` — накопленное значение.

Пример-канон (из `demo_pradd`): `add(0, y) = pi(2, 2)(0, y) = y`.
Следствие для авторов тестов: проекции внутри `h` берутся от
**трёх** аргументов — `pi(3, 2)`, `pi(3, 3)`. `pi(2, ...)` внутри `h` —
типовая ошибка (на ней пала первая версия тестов add/mul).

## 4. Атомы словаря v0.6 **[код]**

- `plus` — арность 2, значение `a + b`;
- `mul` — арность 2, значение `a * b`.

Статус: **чисто-значимые** (только результат, без звука-следов).
Расширение словаря — [открыто].

## 5. Прямая метрика шагов **[код]**

Применение схемы или атома словаря = 1 шаг. **Не** считаются:

- `pi` — свободное переименование, 0 шагов;
- узлы `comp` и `prec` сами по себе (структурные);
- сахар `s(expr)` считается как одно применение `s` к результату
  подвыражения (плюс шаги самого подвыражения).

Эталонные значения (прогон v0.1):

| Программа | Entry | Значение | Прямая метрика |
|---|---|---|---|
| add.pr  | add(5,3) | 8    | 5   |
| mul.pr  | mul(6,7) | 42   | 112 |
| fact.pr | fact(5)  | 120  | 12  |
| fact.pr | fact(7)  | 5040 | 16  |

Примечание: в протоколе разговора ранее фигурировало 13 шагов для
fact(5) — опровергнуто прогоном, канон 12.

## 6. Ошибки и проверки **[код]**

- лексер: нераспознанный фрагмент — `PrError` с позицией;
- `pi(k, i)`: диапазон `1 <= i <= k` проверяется в парсере,
  арность — в раннере;
- арность для `s` (нужен 1 аргумент) и атомов словаря;
- `prec`: отрицательная глубина рекурсии — ошибка;
- entry: имя должно быть определено; аргументы — целые.

## 7. CLI `run_pr.py` **[код]**

    python run_pr.py program.pr                 # исполнить entry
    python run_pr.py program.pr --trace         # трасса вызовов
    python run_pr.py program.pr --entry f(3)    # переопределить entry
    python run_pr.py program.pr --check 120     # сверка значения

`--check` при несовпадении возвращает код выхода 1 (пригодно для CI).

## 8. Звуковой слой (проект спецификации) **[разговор]**

- MathMachine: конечное число лент-счётчиков; операции над лентами;
  исходы вычислений — строго фиксированный набор; семантика — v1.6.
- Sound-надстройка: реестр всех шагов, верификация каждого перехода,
  полная история вычислений (в отличие от перезаписывающей ленты МТ).
- pr2sound: трансляция PR-определений в программу звук-слоя.
