Накрывает: аддендум v0.3 (файлы прошлой сессии в рабочей директории не

## 1. Закрытие открытого вопроса №6: асимметрия builtin/def

**Решение: запрет перекрытия на уровне парсера** (из двух путей раздела
«Что с этим делать» спецификации v0.2 выбран запрет; вариант «переопределение
с приоритетом defs» отвергнут как меняющий семантику).

Правило: имена `plus`, `mul` (атомы словаря) и `z`, `s`, `pi`, `comp`, `prec`
(схемы), а также ключевые слова `def`, `entry` — зарезервированы. `def` такого
имени — ошибка разбора, программа не запускается:

    error: def: имя 'mul' зарезервировано (атом словаря или схема);
           переопределение запрещено (v0.3)

Следствия:
* внутренние узлы `name mul` теперь имеют ровно одну интерпретацию — атом
  словаря; тело `def` больше не может существовать «в тени» атома;
* entry на атоме невозможно (как и раньше: `entry: имя не определено`);
* собственное умножение объявляется под собственным именем. Тестовая
  программа mul.pr переведена на `def mymul` — это ЕДИНСТВЕННОЕ изменение
  тестового корпуса, значения и метрика не изменились (42 / 112).

Обоснование: для системы, чья ценность — гарантированная корректность,
«одно имя — две программы» хуже любой неудобности именования.

## 2. Подтверждение закрытий №3 и №4 (перенос из аддендума v0.3)

* №3: `z` — семейство Z_n, возвращает 0 на любой арности. Строгая нульместность
  ломает канонический корпус: база prec для mul требует двухместного нуля
  (`comp[z, pi(2,2)]`). Дыры не было — была ошибочная интерпретация.
* №4: вычислитель — явный стек кадров, ни одного рекурсивного вызова Python.
  Замеры v0.3: цепочка из 5000 вложенных def — OK за 0.11 с; prec на
  n = 1 000 000 — OK за 2.5 с (steps = 1 000 000).

## 3. Исправление утверждения аддендума v0.3 о comp[f]

В v0.3 было записано: «comp[f] — валидный идиом (comp[f] ≡ f)». Это неверно.
Проверено прогоном: `comp[z]` при вызове с аргументами исполняет z БЕЗ
аргументов (comp с пустым списком gs передаёт f пустой кортеж). Точная
семантика: **comp[f] — вызов f с нулевой арностью**, а не тождественная
функция. Практическое применение — построение констант: `comp[s, comp[z]]`
и подобные. Утверждение в аддендуме v0.3 считать отозванным.
